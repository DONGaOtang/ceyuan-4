# 整合活动的文件分工、参与体验与传播设计

供整合系列大案、明确要求创意/执行/宣传分别成件，或需要深化可玩性、到访理由和自然传播时按节加载。工作组织与确认按 [持续研究生产循环](research-and-content-production-loop.md) 一，旧Step只为能力定位；单项研究、轻量活动和用户指定载体按本次范围处理。这里定义分工与判断接口，故事内容、互动细则、制片、预算和数据仍按对应专业参考完成。

目录：一文件分工；二参与与可玩性；三传播与人物；四跨文件协同；五验收。

## 一、文件分工

**按内容用途分文件，按关联统筹项目。** 同一份文件只承担一组一致的判断或接手任务；独立读者、编辑责任、更新节奏或交接动作不同的实质内容分开维护。文件格式、文件数量和内容分类分别决定，不能把不同职责塞进一个大文档或Excel，再用不同标签声称已经拆分。也不能把同一正文分别导出Word/PPT/PDF当作三种方案。

实际涉及线下内容、执行和线上传播的整合系列大案默认至少形成以下三个独立、实质工作件；纯线上、轻量或单项请求按实际职责裁剪，不强建空的线下文件。用户已明确要求分件时直接采用，无需再次审批文件套餐；用户当轮另有明确单文件或局部范围时按该范围交付。每个工作件按实际编辑用途选择文档、演示、工作簿或必要源件。

| 工作件 | 要让接手者完成什么 | 正文与主维护内容 | 连接方式 |
|---|---|---|---|
| **线下创意与体验方案** | 客户/主创审定内容，继续创作节目与体验 | 主张、开端/承接/收束或真实并列结构；主要内容与代表场景；观众所见所做、选择/反馈/收获、观看价值、系列变化；人物角色与本领、内容资源方向、潜在传播角度与素材机会 | 用unit_id及内容版本交给执行/宣传。资源方向不冒充已确认人手；不承载完整报价、排班、渠道发布日历 |
| **线下执行与总预算** | 项目/现场/采购团队从筹备到撤场、交付与结算兑现承诺 | 实际场次、点位与容量、ROS/人员/供应商/搭拆/技术/动线/排队/服务、资源邀请履约、采购/风险/变更/收尾；全项目唯一费用主账，含线上与线下费用及包含边界 | 执行工作簿可按该用途分表。引用创意内容，不复制全本故事或宣传方案。传播制作时段/费用按asset_id、resource_id、cost_id接入资源与总账 |
| **宣传与内容运营方案** | 传播/内容团队按节点生产、审核、发布、回应与召回 | 受众与议题、线上分支、起势/发展/兑现/后续节点；官方/媒体/KOL/KOC/参与者任务；内容角度转成真实代表稿、素材安排、账号与逐日信息、接收端、评论服务与调整 | 宣传日历归本工作件，计算/筛选需要时配自己的工作簿；引用unit_id/session_id及资源成本主账。传播费用分析可显示引用视图，不再建立另一份独立总预算 |

更完整的大案还要检查以下三种实质任务；只有确需独立审阅、维护或交接时另成件，不能默默把完整正文合并到不相干文件，也不能为了目录好看强建空文件：

| 扩展工作件 | 独立内容与触发条件 | 与核心文件的边界 |
|---|---|---|
| **项目诊断与策略依据** | 地址/项目/经营与口碑研究、客群假设、案例机制、问题优先级和选择依据，需要甲方研究/策略决策时 | 为创意与宣传提供结论和条件；原始证据、未选资料和内部审查另留索引，研究材料不替代策划内容 |
| **用户招募、到访与复访方案** | 谁愿意来、具体利益、触达入口、邀约/预约/候补/通知、出行/时段/价格阻力、商户或社群承接、离场与再次参与；独立运营/CRM/商户团队负责时 | 宣传负责产生有效兴趣，招募负责把兴趣接到可兑现行动，执行负责接待吞吐。若由同一传播团队同节奏接手，可作为宣传工作件中的到访模块，不能遗漏或把曝光当到场 |
| **效果测量与运营调整方案** | 数据口径、基线/采集与覆盖、条件预估、实绩报告、归因限制、周调依据与动作；需独立数据/经营团队接手或跨期反复维护时 | 指标编号和定义只维护一处，其他文件引用本次主判据及采集要求；未发生实绩不填写成果。内容方案不塞全套数据底表 |

导演台本/主持稿、视觉制作简报及源件、商户协同/招商权益、邀约履约等按实际专业交接需要再拆。它们不是每案固定附件；若用户已要求，则完成约定正文/原生文件。可设轻量交付索引列文件用途、版本、主维护人、成熟度与有效入口；索引不再复制整份方案，也不新增必收文件。

## 二、参与与可玩性

从目标人群愿意付出的时间、出行、金钱、注意力及社交成本出发，先说明**活动给他什么具体收获**。分别设计“愿意来”“现场值得停留”“愿意表达”“愿意再来”的条件，它们不自动等价。明星、免费、奖品和拍照可以是吸引因素，不能替代活动主体；没有真实受众资料时把动机标为待验证推断。

Step 2核对受众与行为；Step 4—5把以下问题落实到内容，而非增加形容词；Step 6再用吞吐、工时和成本检验：

- **进入容易**：看到入口能理解获得什么、怎样开始、花多久，预约/入场和前情负担合理；中途加入、不会操作或无手机有可用入口。
- **行动有意义**：用户可以决定路径、材料、难度、角色或表达，选择确实改变过程/结果；扫码、排队和无意义跑点不冒充参与深度。
- **反馈可感知**：动作后看见什么变化、得到何种反馈、完成到什么状态；不能只有任务结束后抽奖，也不能先编观众惊喜和掌声。
- **不同人有各自价值**：初学与熟练、独自与结伴、愿参与与只观看都有适合路径；不愿公开、不愿上台或不拍摄的人仍可得到约定基本体验。
- **变化与再玩成立**：不同选择/任务/作品或真实轮换能产生差异。复演仅改善时间可达性时如实说明；集章、多次签到和换主题名不自动构成复访收益。
- **环境支持内容**：入口与导视让人找到第一步，观看/动手位置、视线、灯光、声音与停留空间支持核心体验；需要安静聆听、专注制作或交谈时分别核对干扰。氛围须说明如何帮助理解、行动或感受，不以装饰数量证明质量。座席、等待、休息、工作人员提示与退出路径进入执行设计；技术参数在勘测后确认，不假定现场已满足。
- **现场代价可承担**：每人所需引导、等待、设备、空间、材料与复位进入执行测算；承诺逐人精修、多人合奏或即时出片时，按实际单人/单组服务能力核对。

可玩性不限于竞技游戏。演出、观看、探索、技能练习、创作、组合选择、合作和可观察演示都可以提供价值；安静观看或专业解释项目不强加扫码互动。选用游戏/任务时按[activity-mechanism-search.md](activity-mechanism-search.md)给完整细则及失败处理，不把复杂积分系统当作好玩证明。

核心体验写成可审阅原型：`unit_id → 对谁/具体收获 → 入口提示 → 所见/所做与选择 → 反馈/完成状态 → 时长与关键服务依赖 → 拒绝参与/出错/资源失效的替代 → 潜在素材 → 下一步`。原型须有实际任务、演示例子、提示语或代表场景，不能只留表头；内容深度按概念/执行用途约定，不默认全套剧本。

用户到访路径再核对：如何发现与理解、哪里预约/问询、谁可参加、价格/时间/出行、怎样找具体入口、等待与容量、到场后能兑现什么、离场带走什么、复访究竟新增什么。判断入口质量不能由曝光量代替。观察/访谈/小样体验/入口试用按可用条件进行；没有实际试验就记拟验证，不冒称真实用户反馈。

## 三、传播与人物

可以有意识地设计值得被发现、记录、讨论和再创作的条件，不能保证形成某次综艺级热度。案例中“公布内容”“官方主动推广”“公众自发行为”“平台/商业放大”与“有人预先编排全链”分别核验；事后运营总结、热榜和机构自报不能单独证明预谋、因果或增量。案例中的共同记忆和情绪也需核对本案人群是否存在，不把怀旧或明星复刻当普适答案。

创意文件把潜在传播机会建立在实际内容上，宣传文件再决定平台与节奏：

`真实内容/人物本领 → 现场可见变化或有意味的时刻 → 路人也能理解的素材 → 目标人群为何愿意转述/表达自己 → 可选的参与或二次创作 → 官方如何承接和兑现`

每个本案需要的核心机会写清表达对象、事实依据、人物/动作/场面、原始素材、可表达的角度、观众自主性、发生条件、现场/线上下一步和失败替代。它可来自能力反差、完成一件具体事、群体共同记忆、可观察成果、地域生活或公众作品，不强制反转/煽情/冲突，也不为了“正向舆论”预写共识。

**人物形象用真实行为支撑。** 可以选择有相关本领和故事的艺人、创作者、商户、专家、员工或参与者，设计让本领被看见的任务、现场关系和表达角度。已核经历、本人可确认的表达、创作角色及待采访内容分开；表演性角色和戏剧脚本明确为创作，人物能力、经历、引语、弱点、观众反应和“素人意外走红”不能编造成事实。人物能否承担内容任务先于知名度；非核心人物取消时保留可审阅的核心体验替代。人物/作品本身就是活动主体时，取消须重选内容、延期或取消并同步原承诺，不能宣称替补等价。

KOL/KOC按实际任务使用：主题解释/示范、相关圈层发现、现场体验记录、问题答复、二次表达或同意触达的召回。每项写客群/地域匹配证据、工作内容、素材/发布权限、交付与费用状态、接收端及观察指标；大粉丝量不证明本地到访。合作发布、官方传播和自然分享分别记录，付费稿不作为自然口碑证据。

参与者为什么分享可能是表达本人的选择、作品、共同记忆、关系或实用发现；若只有宣传口号，没有个人表达空间，不能靠加达人数量补逻辑。拍摄点、声音/视觉辨识、字幕前情、完整素材与剪辑依赖要能让线上观众看懂；现场内容不能只为镜头牺牲参与者实际体验。无授权、禁拍、素材没发生或当场失效时，有可兑现的观看/解释/服务内容替代，不虚构真实好评。

“正向”作为希望产生的讨论方向，不作为用户必须赞同的结果。官方应能回答真实规则、容量、权益、体验和未兑现问题，保留不同反馈并改进内容。不给虚假账号、人造用户反应或冒充自然讨论作为策略；这是事实可信和效果判断的要求，不能把宣传动作当公众评价。

## 四、跨文件协同

拆文件保持共享身份与依赖；不得拆成各自无人负责的三份“完整计划”。沿用[series-campaign-orchestration.md](series-campaign-orchestration.md)二的unit_id/session_id/asset_id/source_id/cost_id/resource_id/metric_id、版本和变更规则，不另建一套编号。每一主维护内容记录所属文件/工作表、主维护人及引用入口。

| 内容主定义 | 归属 | 其他文件引用/需要同步的内容 |
|---|---|---|
| 故事、体验规则的内容意图与角色价值 | 创意；游戏精确细则按约定专业工作件 | 执行接资源与服务条件，宣传接角度/素材/用户承诺；兑现规则变更三方复核 |
| 场次、点位、容量、资源占用、采购与唯一费用 | 执行及总预算主账 | 创意引用真实约束，宣传引用当前时间/名额/成本编号；报名人数与预测口径分开 |
| 宣传节点、逐日选题、账号、稿件与发布状态 | 宣传及其日历 | 执行只接采集/制作/审核占用和成本；不得再维护另一份完整发布日历 |
| 报名/通知/权益兑现 | 指定招募运营工作件或宣传到访模块 | 执行接接待能力，宣传接实际入口；同一字段只维护一处，跨文件可展示注明来源的视图 |
| 指标定义与实绩 | 指定测量工作件/主表 | 三核心文件引用目标与采集任务，不复制独立实绩底表；销售/增量专业规则沿用metrics-flow |

必要摘要、成本分析视图和面向不同读者的提示可重复展示，但须标来源/版本；可编辑主值和完整正文只维护一处。相对链接须指向真实文件/章节或稳定表ID，不能用“详见某案”掩盖空缺。执行Excel可引用宣传日历，宣传工作簿可引用总预算，不要求自动公式跨文件链接；人工同步也必须记录复核，不能把文件已拆开等同已联动。

内容与形式更改会影响资源，场次与候选更改会影响预告/预约，成本限制会影响体验；各变更沿主定义检查真实受影响工作件、负责人、旧/新值、待修改内容、通知与复核状态。保留未落实条件；需改变已确认目标/主创意/预算等取舍时，按持续循环一处理决定；已选方向的常规内容深化与局部修复继续，不逐Step重审。

## 五、验收

Step 7审阶段已到期内容，Step 9在本次实际工作件完成对应检查，不能把未到交付阶段当作漏交：

1. **文件职责**：三个核心工作件各自能完成约定判断，不依靠另一个文件中的隐藏全文；创意里无采购长表，执行里无完整传播正文，宣传里不重建总费用主账。用户只要一类时没有自动扩成全套。
2. **首次体验**：沿一个真实拟案，从邀请到进入、第一次选择/观看、反馈/结束走读；能指出实际所得及成本，找出不会玩、怕社交、不拍摄、途中加入和资源失败时的替代。桌面走读不冒称用户实测；参与阶段与累积负担按研究生产循环四检查，不强建固定人群包。
3. **内容承接**：开端提出什么，后续如何改变/回应，结束留下什么；并列结构说明不同视角，不强编剧情。按研究生产循环四并排读相邻实际稿件，指出新增价值或必要重复理由，空转已回写内容与排期；复演和真变化可辨识，可玩点不是只剩集章抽奖。
4. **传播成立条件**：选一个拟传播时刻，追到实际内容/人物依据、素材、代表稿、目标受众表达理由与接收端。按 `new-media-campaign.md` 核合作实际稿件的贡献并从任一内容走读有效入口；带项目认知/到访目标时按创意质量门禁检查无提示记忆与到访理解。热点不发生、人物取消或素材失效时仍有真实可用路径，不同反馈不被虚写为一致好评。
5. **跨文件变更**：沿一个unit/session或人物变更定位创意、执行、宣传及适用扩展件；时间、容量、权益、预算和稿件的引用可复核。接待状态异常按 `critical-path-delivery.md` 同步实际服务、报名和宣传；运营继续/调整/暂停/恢复按 `metrics-flow.md` 检查条件和履约影响，不只检查链接存在。
6. **用途与成熟度**：文件存在、内容可审阅、源件可编辑、资源已落实、用户已确认、动作已执行和效果已测得分别记录。不得把代表稿当全部成稿，拟议爆点当既成话题，公式通过当体验有趣。

实际观察资料不足时可通过内容评审用途，继续把可玩性、到访意愿和传播接受度标待验证；不能用模型自评分替代真实反馈或传播结果。未解决影响本次用途的关键缺口时修复对应内容与关联，不凭增加文件数量判升级完成。
