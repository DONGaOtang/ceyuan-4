系列事件营销按需加载 [统筹模块](series-campaign-orchestration.md)“三、项目研究与案例迁移”“四、系列活动与邀请”；有线上任务才读“五、线上分支与逐日内容”。项目诊断决定可碰撞素材，创意产出要说明内容单元如何持续、哪些实际场次兑现；承诺继续参与或复访时再说明下一次的具体价值。

## 一、5 Whys 动机拆解

**追问规则**：从「表面需求」往下挖，顺着每次回答继续追问，直到明确希望改变的处境、受众收获和成功条件——**不强制凑满 5 次**。「钱、权、关系、怕」可作为检查遗漏的线索，不能替用户认定隐性动机；知识理解、艺术表达、公共服务与共同纪念也可能是活动的主要目的。每次追问必须基于上一次的回答，不是机械重复「为什么」。

**动机类型清单**（判断归属，别硬套）：

- 募资 / 融资信号：给投资人看信心
- 渠道压货：给经销商看决心，逼订货
- 向上汇报 / 政绩：给老板或上级看成果
- 留人 / 凝聚力：稳军心，防离职
- 卖货 / 转化：直接冲销售
- 品牌占位：抢心智，压竞品
- 危机公关：灭火，挽回声誉

**判据**：同一句「办发布会」，以募资还是销售为目标会改变内容与承接。缺少会改变当前取舍的目标信息时，针对缺口核实，只暂缓依赖该答案的决定；已授权的研究、条件原型、文稿与生产Brief继续，不推定隐性动机或重复已有确认。

将用户明确目标与策划推测分开；不能仅由“国企、经销商、员工、艺术节”等标签推出政绩、压货、留人或出圈。对内容的需求也要具体：希望谁读懂哪个问题、看见什么、获得何种体验或作出什么判断。只询问真正改变当前决定的缺口；已授权方向的研究、草案与深化继续，实质取舍按研究生产循环处理，不重复已取得的确认。

## 二、交叉网络（可选发散工具）

本节提供一种发散方法：**锚点 × 可变域 → 内容候选。** 反直觉是可选结果，不是所有创意的目标；方法不能替代真实内容、受众所得和生产条件。 交叉网络是发散的**乘法引擎**——把「线性组装 N 个方向」升级成「碰撞出 N×M 个组合」。

> **方法关系**：需要新方向时按当前问题选择输入与创作方法。横纵分析可提供结构/制作素材，心理机制提出待验证行为假设，跨界移植与市场信息可提供动作、反向问题和条件；它们不必须先经过交叉网络才能采用。交叉是可选发散工具，不规定候选数量或统一热点顺序；收敛与对抗核验针对实际内容和关键假设。已有母题直接深化相关内容。

### 锚点域（本轮碰撞的共同依据）

活动的「核心元素」——这场活动/品牌「我是谁」：

| 活动类型 | 锚点（示例，动态判断，不硬套） |
|---|---|
| 发布会 | 悬念（One more thing） |
| 快闪 / 市集 | 稀缺 |
| 答谢会 / 私享会 | 专属 |
| 招商会 | 信任 |
| 年会 / 团建 | 归属 |

**用法**：需要碰撞时，先明确本轮共用的核心内容或问题；跨单元可以有各自锚点，但须说明与母题的关系。表中仅为示例：发布会也可能以可验证能力为锚点，年会也可能以真实贡献为锚点；必须从本项目需求和已有材料推出，不能按活动名自动赋值。反馈推翻锚点依据时重核，而不是将“不变”当永久约束。

### 可变域（6 个，动态生成，不硬编码穷举）

| 域 | 关键词 | 值怎么来 |
|---|---|---|
| H 热点 | 及时性 | 本轮相关且可核的话题；原始事实与情绪推断分开，无相关话题时不采用 |
| C 文化 | 共鸣 | 圈层暗号、时代记忆、集体情绪、亚文化 |
| E 情绪 | 底层 | 受众此刻的焦虑/好奇/炫耀/归属/怕落单（喂推理卡，见六） |
| X 跨界 | 借机制 | 不相干行业解决同一动机的机制（喂跨界移植，见八） |
| S 感官 | 五感 | 视觉/听觉/嗅觉/触觉/味觉的具体动作 |
| T 冲突 | 张力 | 反常识、反转、悖论、禁忌、留白 |

**选择原则**：按本轮问题和已有内容选择有作用的输入域，不规定先用热点/情绪/跨界或域数；关键输入不足就定向补研究，不用更多组合遮盖缺口。

### 交叉算子（3 种）

1. **嫁接**（杜蕾斯法）：把外部要素「焊」到锚点上——拉伸、弯曲、组合、替换。
2. **双域碰撞**：锚点 × 任一变域，找反直觉交集。
3. **三域撞击**：锚点 × 两个变域，撞出「只有这个组合才有」的创意。

### 产出规则（守「发散收敛分离」）

- 每次交叉只产出「**一句核心概念 + 一句 self-steelman（为什么有意思）**」，**不做任何评判**。
- **保留差异**：需要打破惯性时可以尝试反直觉组合，但不因“不够新奇”提前删除清晰、可信或适合观看的候选。收敛及对抗核验依据实际内容价值、目标和条件，不以新奇度覆盖这些判断。
- **动机做第一道筛**：交叉候选生成完毕后，先用 Step 2 的目标行为和 Step 3 的主判据粗筛，动机不对、不服务已确认目标的不进收敛候选。发散记录保留，筛选不倒灌为边生成边否定。
- **时空轴自检**：按实际日期、资源与持续维护责任判断候选是单次发生、跨期系列还是持续运营，见 `axes.md` 五；时空形态不预先决定声势、关系或销售目的。持续机制需要相应内容与服务能力，单次原型也不能无依据声称长期有效；每天/每周/会员日常是可选节奏，不是周期型配额。
- 未选方向时生成足以覆盖关键差异的候选，再按人群价值、专属性、持续原料与生产条件比较；不规定统一数量，也不以最反直觉作为优先判据。已选方向、常规更新或局部修稿直接深化，不重开发散。

### 系列创意的展开

周期型项目先从目标人群、真实内容、历史反馈和已确认资源中找锚点；商业地产才叠加地址、商圈、租户与项目口碑。再为候选补上“全期持续体验 / 重点场次 / 轮换变化 / 复访或继续关注理由”。形式可以是持续装置、节目、专业内容、公共服务、观看或共创，不能把所有分支都强制写成打卡、任务和投票。

采用的核心内容单元按统筹模块保存 `unit_id` 与具体内容；复演与不同日期落到 `session_id`。同一母题下的各单元须有实际贡献，同作复演如实注明，不能只换名字和日期冒充新增内容。有线上任务时，与对应核心内容一起提出分支：线上给谁什么价值、看完做什么、实际接收端如何兑现、怎样承接下一轮；有线下内容才核现场连接。纯线上核线上内容/服务，纯线下闭门系列不强加线上分支。征集/任务类才补截止、判定、容量和兑现失败处理；观看、探访、攻略或专业解释按各自价值设计。

创意收敛时把最强反驳写到候选旁：假如观众不愿再次参与、接收端不能承接、内容素材生产不足或线上关注未达目标行为，具体是哪条机制失效。商业地产有商户任务时再检查租户承接；外部证据与策划推演分开，不能为了让机制看似成立编造客群需求或历史效果。

### 热点采用的相关性与时效检查

> 采用热点须有与本案内容、人群或节点的实际关系；相关输入可以是事实、问题、作品、服务需要或情绪，不只贴热点标签，也不强制提炼集体情绪。

- ❌ 蹭：「蹭某某明星塌房」——贴标签，短命，low。
- 待验证推演：「部分讨论可能关注表达是否真诚」——须检查原始讨论与适用人群，不能由单个争议推出集体情绪，也不能宣称该情绪长效。

**采用热点时**：按 `search-paths.md` 选择相关来源，按 `source-access-and-login-workflow.md` 实际检查访问状态并读取；事件事实、受众情绪推断及本案采用决定分别记录。不能验证的保留假设，缺少相关热点不阻断其他材料创作，也不把热榜检索当全部创意的启动前提。

热点与情绪输入仍须先判断相关性。公开传播项目可用可核实的实时话题，内部、专业或学习项目可从已获授权的当前问题、反馈和复盘提取情境；没有相关热点则记录不采用的原因，使用适配的文化、感官、冲突等域，不强搜娱乐热榜。锚点、输入与比较按本轮问题选择；已选方向无需重开全部交叉动作。一手需求信号不是方法有效的证明，外部事实仍按主文件核验。

### 用法（四步）

1. **界定锚点**：本轮确需新方向时，从已核内容与受众需要确定核心问题；已有母题沿用有效主定义。
2. **取适用输入**：按当前问题取得事实、作品、反馈、机制或文化材料；相关热点/情绪可核时才采用，不强制先拉热榜。
3. **形成内容候选**：按适用方法创作，必要时用嫁接/碰撞；反直觉可尝试但不替代清晰、可信、观看或服务价值。
4. **比较采用**：候选说明核心概念与最强支持理由，再以目标人群、实际内容、系列变化和资源条件收敛；具体场景和产出在选定方向继续展开，不用候选数量或新奇程度代替内容。

### 一个走通的例子（发布会）

- **锚点**：悬念。
- **实时拉热点**：假设当下热点是「某综艺靠淘汰赛翻红」。
- **嫁接**：悬念 × 综艺淘汰机制 → 「发布会不公布全貌，观众投票解锁下一个模块」。
- **三域撞击**：悬念 × 情绪(想炫耀) × 感官(嗅觉) → 「凭气味解锁的邀请函」。
- **双域碰撞**：悬念 × 冲突(留白) → 「发布会全程不出现产品正面，揭晓留到最后一秒」。

三个候选，一个锚点 × 三个变域。这就是乘法：组合爆炸，而不是线性组装。

## 三、横纵分析（贯穿全流程的元拆解方法）

> 横纵分析不是「Step 5 创意机制」的专属工具，是**贯穿全流程的元拆解方法**——任何「需要拆解」的节点都能挂载它：Step 1 拆信息、Step 2 拆行为、Step 3 拆经营、Step 5 拆创意、Step 6 拆环节/执行。
> **挂载点由流程节点决定，拆解对象由活动类型决定**（见 `event-types.md` 的「核心要素」），拆解方式统一（纵向演变 + 横向截面）。**按需挂载，不强制**——哪里需要拆哪里才用，不是每个节点都跑一遍。

本节给「问什么」，具体「去哪搜」见 `references/search-paths.md`，具体「怎么访问、是否登录、怎么降级」见 `references/source-access-and-login-workflow.md`。别只问不搜，也别把访问受限的内容写成事实。

### 纵向（时间轴）：追这个「拆解对象」的演变史

1. **对象历史**：这个「拆解对象」过去怎么做的？形态演变了什么？
2. **品牌历史**：这个品牌之前做过什么？口碑如何？有没有历史包袱？
3. **翻车案例**：同类做法过去怎么失败的？踩过什么坑？
4. **演变动机**：为什么**在这个时点**会演变出当前形态？

### 横向（同期截面）：切这个「拆解对象」的同类对比

1. **同类做法**：最近同类「拆解对象」怎么做的？「活成了什么样」，不是参数对照。
2. **真实口碑**：评论区、社区里的真实声音（非官方宣传）。实际使用方式和官方定位有没有偏差？
3. **生态位**：这个做法是填补空白，还是正面抢谁的蛋糕？

### 拆解对象怎么定（关键，别用通用清单套）

「拆什么」不是通用环节清单，是**活动类型决定的**：

1. 用 `axes.md` 推导轴定位活动类型
2. 查 `event-types.md` 该类型的「核心要素」——这就是「要拆的环节/对象」
3. 选择影响本轮判断且证据仍不足的关键对象，做适用的纵向与横向对照；不为逐个要素完成配额重复检索。

例如发布会若关键未知是演示证据与理解路径，就拆相应任务、材料和解释；招商会若关键未知是合作条件与尽调，就拆真实授权和后续承接。类型表的悬念、峰值、媒体或逼单仅是可调查线索，不能不经判断全部拆一遍；通用流程名也不能代替本次实际内容。

### 环节拆解：从案例展示里拆出环节 + 综合（拆「动作」，不是找「环节拆解源」）

案例展示（活动复盘、打卡笔记、案例文章）里就藏着环节信息，虽然不全，但它是这个活动的**对标路径**。环节素材不缺「源」，缺的是「拆」这个动作——**案例展示是原料，横纵分析是加工，综合是产出**。先拆已取得展示；缺少规则、制作、更新、服务或效果依据时继续定向找原始资料、反馈与反证，不把展示足够当作默认结论。

**三步拆法：**

1. **横向逐个拆**：选择可读取、足以比较关键机制与差异的同类案例，从展示里拆出环节链（预热 → 主体 → 高潮 → 收尾，具体到每个环节做了什么）；样本有限时标明限制，不为数量补不相关案例。
2. **纵向追演变**：选择需要解释变化的关键内容/制作/服务对象，追其实际演变与原始依据，不按数量或活动名预设打卡、稀缺。
3. **综合分析**：把 N 个环节链摆一起，拆出三样东西——
   - **样本共性**：所读案例中哪些内容或动作重复出现、在什么条件下有价值；不能从快闪类型名推出必有稀缺、打卡或社交传播
   - **差异创新点**：各案例的差异化设计（茅台的话题势能、泡泡玛特的抽盒仪式感）
   - **环节逻辑**：环节之间的先后因果（为什么「稀缺」要排在「体验」前面）

假设示意（并非已执行检索或数量要求）：若所读品牌快闪呈现预告、限时体验与后续服务，则比较具体内容、参与负担、更新及承接条件；共性只代表该样本，不推出所有快闪都需稀缺、打卡、销售或自然扩散。

### 细化：拆出来的环节，落到「需要哪些内容、细到什么程度」（第二环）

横纵分析拆出的「维度 / 环节 / 模块」是抽象框架，**别停在这**。往下细化一步——每个环节，落到「需要哪些内容条目、细到什么程度」，具体层就是这么来的：

1. **逐个环节细化**：拆出的每个环节（快闪的「稀缺」「打卡」、店庆的「引流」「转化」），问「这个环节要落地，需要哪些具体内容？」——例：店庆「引流」→ 需要「引流渠道（线上/线下）、引流物料、引流优惠、引流目标」。
2. **定颗粒度**：按文件用途、内容复杂度与活动规模定深度：概念阶段写到能判断内容是否成立，执行阶段写到能据此准备与行动；大型活动补具体时间、场地、责任、费用等。轻量活动减少单元和管理细节，仍须讲清实际发生什么，不能只写「大概做什么」。
3. **列内容条目**：每个环节先列所需内容，再区分「须核实的事实/资源」与「策划应提出的内容」。事实从用户资料或可靠来源填，缺失则保留状态；故事、议题、玩法细则、邀请文案、主持问题等创作任务，由策划在授权范围内给出具体拟案，不能全部留空转交用户。未选方向写当前取舍需要的具体候选或原型；方向已定直接深化当前内容和实际Brief，随形成保存，不按旧Step编号限制文件。

> 关键：具体层 = 「所需内容」+「可核实事实」+「可审阅拟案」。完整链保持为 **拆（维度环节）→ 细化（内容条目+颗粒度）→ 填值（查证/针对性提问/授权创作）→ 组装（落成内容与必要表格）**。外部未知不得编造；应由策划完成的正文不得以“待主创深化”整项推迟。少数外部缺口影响核心成立时，在该处给具体替代拟案或明确影响，其他可完成内容继续完成。

内容条目须能回答目标由什么实际材料支撑：产品承诺对应演示输入、动作、输出和判断口径；论坛议题对应真实问题、证据位和追问；演出主题对应人物行动或场景；传播任务对应实际稿件及接收入口。表头齐全、标题漂亮、流程顺序完整都不能替代这些材料。选定创意后的主要单元按 `narrative-and-concept-delivery.md` 展开，场景衔接要解释信息或体验怎样承接。

## 四、信息来源优先级

关键词任务、实际查询/读取/看图及多源分析按 [持续研究生产循环](research-and-content-production-loop.md)“二、研究接口”“三、视觉取材接口”与检索/访问专业规则完成。本文件提供拆解与创作方法，不替代真实检索记录。横纵对照须指出证据、可移植动作、变化/缺口及本案采用决定；不能仅回答通用问题。

一手来源优先。多个媒体引用同一错误，会造循环印证假象。

| 信息类型 | 一手来源 | 可信二手 |
|---|---|---|
| 活动案例 | 品牌官方账号、活动回顾、参会者笔记 | 权威媒体原创 |
| 用户口碑 | 小红书/知乎/豆瓣真实评论、现场视频 | 转载聚合（慎） |
| 行业趋势 | 行业报告、协会数据 | 媒体解读 |
| 商业数据 | 官方公告、工商/财报 | 券商研报 |

来源数量和声明强度统一按 [证据规则](anti-hallucination-and-evidence.md)“三点二、按声明性质决定证据要求”执行。一份合格官方材料可证明其公布的机制或规则；效果、代表性口碑及高影响争议主动找独立交叉证据，不能把两个转载当确认，也不能把官方自报当实际增量。

## 五、信息充分性自检

需要新方向或新增内容时，按影响本轮决定的关键未知检查：

1. 纵向能讲出这个品类/品牌的故事吗？有断层吗？
2. 横向是否覆盖会改变本轮选择的主要替代活动、相近机制和条件差异？尚缺什么，不追求同类清单穷尽。
3. 关键声明有适用的证据吗？是否把公布内容、个体体验、代表性判断与因果效果混在一起？按证据规则是否仍有访问或交叉核验缺口？
4. 采用市面案例时，是否拆到实际内容、动作与条件，而不只有“很火”？不足则定向补研究；已有项目原料、确定母题与不依赖缺口的条件原型继续，不要求所有创意先证明疲劳或竞品空白。
5. 当前项目有没有自身可用的内容原料：产品证据、真实案例、人物经历、文化材料、作品或具体问题？外部灵感不能代替项目内容；缺的是事实就核实，缺的是创作就明确由策划提出拟案。

未解决的可发现问题继续定向检索；在本轮权限或公开资料下无法解决的，保留缺口与条件式推断。材料不足不能靠凑来源或捏造案例解决。

## 六、心理机制推理卡（不是名词表，是推理依据）

按本案内容与关键假设选择有依据的机制，不设数量配额。**每个机制是一张推理卡，四个字段：理论出处 → 触发条件 → 失效边界 → 反例。** 选机制不是「从名词表里挑一个」，是「哪个机制的触发条件匹配当前场景」。

> 策划的难点从来不是「知道有哪些心理开关」，是「为什么选它、什么条件下它会失效」。只给名词 = 拍脑袋；给了触发条件 + 失效边界 = 推理。

| 机制 | 理论出处/检索线索 | 可检查的假设条件 | 需要考虑的失效解释 | 可尝试表达 |
|---|---|---|---|---|
| 好奇缺口 | 信息缺口理论（Loewenstein） | 受众对该主题已有兴趣；缺口「刚好够补」 | 缺口太大=漠不关心；太小=没兴趣；受众对品类零兴趣时彻底无效 | 标题/悬念/不剧透 |
| 社交货币 | 疯传（Berger） | 内容能让分享者显得「内行/有钱/有趣/有品」 | 分享成本高；内容不稀缺、人人可复制 | 打卡点/专属身份/谈资 |
| 稀缺 | 影响力（Cialdini） | 稀缺「真实且外显」：真限量、别人也在抢 | 假稀缺被识破→信任崩塌；供过于求时失效 | 限量/限时/名额 |
| 损失厌恶 | 参照依赖选择（Tversky、Kahneman） | 受众将某种变化理解为相对参照点的损失；需验证实际参照点与情境 | 不能等同于禀赋效应或沉没成本，也不能从倒计时直接推断转化有效 | 准确说明真实的到期条件或机会成本，不制造虚假损失 |
| 身份认同 | 社会认同理论（Tajfel） | 有清晰的内/外群体边界，参与能「确认我是谁」 | 圈层模糊、无价值观站队时弱；强加身份被反感 | 圈层暗号/价值观站队 |
| 从众 | 从众实验（Asch）、社会证明 | 不确定情境下、看到「相似他人」在行动 | 确定性情境下从众弱；「相似他人」缺失时弱（大V ≠ 我） | 晒到场/排队/爆满图 |
| 情绪峰值 | 峰值与结尾对回顾评价的研究（Kahneman 等） | 把关键内容与收束作为需要检查的体验节点，实际影响须结合活动情境验证 | 原研究不能证明所有活动必须有强烈正情绪或独一无二的高潮，也不能补救整场内容缺失 | 让关键段落与结束方式服务完整体验 |

**用法**：先明确本案实际人群、目标、内容和已取得反馈，再选择有对应条件的机制作为假设；涉及心理解释时核对适用理论与原研究边界。未知情绪不先填结论，没有相应需要也不必选心理机制。

心理机制表仅供提出待验证的行为假设，不是对本次人群的心理诊断，也不保证报名、分享、认同或购买发生。必须回到已获得的用户材料和情境限制；不能以一个理论名词抵消内容缺乏、动作负担或受众不需要。观看、理解、判断与建立信任同样可以是目标，不必都变成现场互动。

> **「峰终定律」在此仅作体验检查线索**：峰值和结尾可能影响回顾评价，不能推出“记忆只由峰值和终值决定”，更不能只写高潮而删掉其他内容。Step 6 与 Step 8 仍须保证过程完整。理论出处可核对 [Kahneman 等，1993，APS 论文摘要](https://www.psychologicalscience.org/journals/psychological-science/j.1467-9280.1993.tb00589.x/)；损失厌恶的参照依赖表述可核对 [Tversky 与 Kahneman，1991，QJE 论文摘要](https://academic.oup.com/qje/article-abstract/106/4/1039/1873382)。两项原研究不直接验证本次活动效果。

## 七、动机 → 情绪 → 行为 推理链

推理链是「选机制 + 激发灵感」的工具，不是「每个创意的关卡」。用它验证机制选得对不对，同时从情绪推到行为动作（发散燃料）：

1. **定位情绪底层**：这个受众，现在处于什么情绪状态？（焦虑 / 好奇 / 想炫耀 / 怕落单 / 渴望归属…）
2. **选机制**：用推理卡，找「触发条件匹配当前场景」的机制。不是挑顺眼的，是挑「触发条件成立」的。
3. **推行为**：这个机制触发后，预期受众做什么？（转发 / 到场 / 下单 / 留资…）用哪个设计动作承接这个行为。

**用法边界**：推理链走不通时，先检查是否缺事实、情境不匹配或本案不需要心理机制，再决定补研究、改机制或不用；不能把情绪假设写成用户事实。该工具帮助选择机制，发散不逐项套作门禁；采用后须在当前工作包完成内容、关键证据与对抗核验，不等旧Step7编号才纠错。

## 八、跨界移植（发散增强角度，防平庸）

当内容只是照搬同行且实际价值不足时，可尝试其他行业来问：**这个行业怎么解决同一动机？**

| 不相干行业 | 它解决的动机 | 可移植的机制 |
|---|---|---|
| 纪念活动 | 仪式与内容收束 | 比较如何呈现真实纪念事由、贡献和结束动作；回顾体验影响待本案核对，不承诺终身记忆 |
| 游戏业 | 留存 / 上瘾 | 如何设计回访钩子、成长线、社交绑定 |
| 宗教 | 归属 / 峰值 | 如何用反复的仪式制造集体情绪高潮 |
| 游戏/技能练习 | 完成反馈与下一轮获得 | 比较本轮真实成果、难度选择与下一次新增所得；不把已投入等同损失厌恶或证明回访有效 |
| 综艺 | 悬念 / 追看 | 如何用淘汰、晋级、揭晓制造追着看 |

**用法**：发散卡住时，抽一个不相干行业，把它解决同一动机的机制移植过来。移植不是照搬，是「借它的机制，换你的场景」。它是可尝试的方法；是否改善内容以本案原型、受众价值和实际条件比较，不宣布普适有效。

## 九、市场信息碰撞（创意至上增强层）

核心一句话：**市面信息不是拿来抄的，是拿来拆成信号，再和用户资源、活动锚点、心理机制相撞。**

本轮采用外部输入时，按 `search-paths.md` 与 `source-access-and-login-workflow.md` 完成针对问题的实际查询、打开、读取/看图及来源核对，保留访问缺口与条件推断；不要求先完成旧Step1才能创作或保存草案。已有研究可按时效与适用性复用，反馈改变关键判断时再补研究。案例须提炼可迁移动作与限制，不能原样搬进方案。

### 1. 四类市面信号

| 信号 | 去哪里拿 | 拆成什么 |
|---|---|---|
| 热点情绪 | 依 `search-paths.md` 选择相关讨论及原始事实入口，热榜只是线索 | 所见样本表达的情绪、疑问或需要及其范围；不能代表全体人群 |
| 平台玩法 | 实际相关平台的内容、参与说明、评论和原始制作记录 | 看见何种表达或机制，哪些可见反馈支持采用假设，效果仍缺什么证据 |
| 竞品空白 | 同类项目、官方记录、案例及真实反馈，入口依检索主定义扩展 | 所查样本中的共性与差异、可能未被满足的需要；未找到不等于无人采用 |
| 用户反向信号 | 小红书评论、抖音评论、微博吐槽、知乎长评、B站弹幕 | 用户觉得尴尬、土、假、高冷、无聊、麻烦、没必要的点 |

主动检索支持与反驳候选的材料，记录哪些判断受影响。反证要求按 [证据规则](anti-hallucination-and-evidence.md)“三点三、主动反证与置信度”执行：未发现相关反向材料或无法查看评论时如实留缺口，不强制正反各 1 条。主动提出失效条件可以辅助审查，但不能冒充外部用户评价。

### 2. 信号提炼格式

需要用市面信息支持候选时，保留以下可追溯内容；已有充分依据可引用原记录，不重复填一套表，也不把交叉网络设为唯一创作入口：

| 字段 | 写法 |
|---|---|
| 原始信息 | 看到的热点/案例/评论/玩法，绑定来源、检索时间与访问状态；无法核实则标假设 |
| 底层信号 | 所见事实可能支持的情绪、机制、需要或空白及竞争解释；疲劳判断引用研究生产循环四，不从互动下降直接推出 |
| 可用动作 | 能转成什么现场动作、传播动作、互动机制 |
| 失效边界 | 什么情况下会显得硬蹭、过时、廉价或不适配 |

若原始信息来自登录墙、搜索结果页、不可见评论区或付费平台，必须在原始信息里标注访问状态；不能验证的信号只能用于方向性假设。

以下为机制推演示意，不是已核实的实际案例或效果数据：

| 原始信息 | 底层信号 | 可用动作 | 失效边界 |
|---|---|---|---|
| 假设观察到某打卡点有较多自发分享 | 可能存在记录到访的动机，需核对内容、样本及其他原因 | 尝试让真实体验留下可带走的记录 | 记录没有实际内容价值或观众不愿公开分享时不成立 |
| 假设看到用户吐槽发布会冗长空泛 | 可能更需要具体信息或证据，不能直接推断其想上台互动 | 尝试用实际任务演示替代重复介绍，再按目标决定是否邀请参与 | 信息被游戏隐藏、互动造成负担或降低专业清晰度时失效 |

### 3. 六种碰撞公式

用这些公式把市面信息撞成创意，不要只做案例拼贴：

1. **用户资源 × 热点情绪**：把用户已有资源变成承接当下情绪的动作。
2. **活动锚点 × 平台玩法**：把一个流行玩法改造成该活动独有的仪式。
3. **竞品空白 × 心理机制**：别人没占的位置，用一个明确心理机制打穿。
4. **用户反向信号 × 反转设计**：把用户讨厌的点反过来，做成创意主张。
5. **跨界机制 × 市面疲劳**：当同行玩法都腻了，借不相干行业的机制破局。
6. **感官动作 × 传播钩子**：把视觉/听觉/嗅觉/触觉/味觉变成用户愿意拍和讲的理由。

### 4. 创意闪卡输出

需要比较未选方向时，可用下表的闪卡表达实际差异与关键条件；已选方向、局部续作或已授权成案直接写需要的具体内容、稿件和Brief，不把闪卡设为文件生成前置门禁：

| 字段 | 要求 |
|---|---|
| 创意名 | 能被目标读者复述、准确指向内容，不设统一字数 |
| 一句话概念 | 活动到底有什么不同 |
| 内容依据 | 写采用的事实、作品、反馈或方法及其怎样改变拟案；用了信息碰撞时再说明具体输入 |
| 内容动作 | 说明在实际场域看见、交流、选择、操作或完成什么；未知实现条件标状态 |
| 表达价值 | 有传播任务时说明可自主转述的真实内容、素材与接收端；无公开目标时写理解或私下表达价值 |
| self-steelman | 一句说明它为什么可能赢 |
| 待验证假设 | 用户会因为什么而报名 / 转发 / 留资 / 到场 / 购买 |
| 关键核验 | 对影响当前决定的未知选实际核验、条件拟案或预检；用何材料、何时判断、失败怎样处理，不为每张卡强做AB |

**实验验证规则**：创意闪卡不是实验报告，但必须暴露它赌的关键假设。严格格式见 `experiment-validation.md`。如果样本不足，只能写「方向性预检」，不能写成确定结论。

### 5. 禁止项

- 禁止只把热点名贴到活动主题上；须有可解释且经核对的内容、人群或节点关系，不强制以情绪作为唯一输入。
- 禁止把别人的活动环节照搬；要拆机制再换场景。
- 禁止仅凭案例宣传推断用户反应；能获取评论、访谈、实际使用反馈时交叉检查，获取不到则明确限制，不虚构评论区或把少数评论代表全部受众。
- 禁止只输出“高级感、沉浸式、年轻化”等形容词；须说明实际场域的内容、观看/交流/参与方式和受众所得。
- 禁止为了显得有创意而牺牲主判据；动机错，再新也没用。
- 禁止只靠会议室判断宣布创意会爆；对影响当前取舍的用户反应假设，按可用证据与条件安排适用核验、原型或必要预检，未验证效果保留未知。
- 禁止把框架、选题列表或待开发事项当作已完成内容；进入成案的主要单元必须有对应的实际说明和本阶段所需拟案，创作状态与外部资源确认状态分开写。
