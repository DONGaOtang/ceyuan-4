# 利益相关方行为改变模型

活动的本质不是“办一场东西”，而是在有限时间、空间、注意力和社会压力里，让关键人群发生目标行为改变。

## 一、使用时机

目标与受众行为相关时，使用本模型明确当次目标行为；Step 2 只是能力定位。资料不足时写出可观察的目标假设、具体缺口与影响，继续完成有依据的研究、条件原型和已选方向深化，不把未知动机写成已验证。只有依赖该目标或行为依据的确定性判断/定稿等待补证或实质决定；独立工作继续。确认与工作组织按 [持续研究生产循环](research-and-content-production-loop.md) 一，不恢复逐Step硬停。

## 二、行为改变表

| 角色 | 当前行为 | 目标行为 | 阻力 | 收益 | 推动机制 | 证据等级 |
|---|---|---|---|---|---|---|
| 参与者/用户 | 现在不来/不发/不买/不信/不参与 | 活动后要做什么 | 时间、成本、尴尬、低信任、无感 | 情绪、身份、利益、关系、知识 | 邀约理由、现场动作、激励、社交证明 |  |
| 付款方 | 现在担心预算/ROI/风险 | 愿意批预算/追加资源 | 不确定性、问责、预算压力 | 可证明价值、面子、汇报材料 | 预算价值架构、风险预案、复盘证据 |  |
| 拍板人 | 现在尚不能判断价值或风险 | 能依据目标、方案与约束作决定 | 信息不足、取舍不清、风险未知 | 可理解的价值与可检查条件 | 开篇明确问题、选择和依据，按实际内容形成记忆 |  |
| 执行团队 | 现在各自为战 | 按关键路径交付 | 边界不清、时间冲突 | 任务明确、风险可控 | RACI、关键路径、验收标准 |  |
| 销售/渠道 | 现在只拉人/等结果 | 主动邀约、识别、跟进 | 话术弱、名单乱、CRM 麻烦 | 线索评级、商机推进 | 邀约脚本、适用识别及按可履行时点跟进 |  |
| 赞助商/合作方 | 现在观望 | 投入钱/资源/背书 | 回报不清、履约不可信 | 曝光、线索、关系、内容资产 | 权益矩阵、履约 tracker、ROI report |  |
| 政府/媒体/机构 | 现在不确定支持 | 到场/报道/背书 | 口径风险、规格风险 | 公共价值、产业叙事、传播价值 | 领导动线、通稿口径、合规流程 |  |

## 三、判断规则

- 当前行为必须是动词，不是画像。例如“销售不主动邀约”比“销售积极性不足”更可执行。
- 目标行为必须可观察。例如“由指定销售在本项目已确认的响应时点前完成相应线索跟进并留记录”，比“提升销售转化”更可检查；时点由需求、承诺与团队能力确定。
- 阻力要具体到行为卡点：不信、嫌麻烦、没面子、怕担责、没有话术、没有时间。
- 推动机制必须能落成设计动作：邀请函、现场仪式、标签、任务、权益、内容资产、复盘报告。

观看型活动可用完整观看、能够复述/比较、主动选择后续内容等可观察信号承接；学习与服务活动按理解、任务完成或服务获得来判断，不强制上台、分享、留资、购买。“钱、权、关系、怕”是动机探查角度，不是必须强加给参与者的真实心理；没有证据应保留替代解释。

系列内容在可识别范围内区分首次接触、已看未到、已参与与复访者，分别核对所知信息、阻力和本轮实际所得。缺个人识别数据时使用明示的样本或假设，不能宣称已完成全体分层；低互动可能来自分发、时机、入口或重复负担，按 [运营决定](metrics-flow.md) 八补证后调整，不直接判疲劳。

## 四、冲突检查

行为改变之间可能打架，必须显式标出：

| 冲突 | 例子 | 修法 |
|---|---|---|
| 用户轻松 vs 销售转化 | 用户想玩，销售想收线索 | 把留资嵌入体验动作，不做硬拦截 |
| 领导规格 vs 社媒传播 | 政企仪式要庄重，平台内容要好看 | 拆成仪式区与传播区 |
| 赞助曝光 vs 品牌主场 | 赞助商要露出，主办方怕被稀释 | 设置权益层级和露出边界 |
| 创意冒险 vs 审批安全 | 年度项目想新，审批怕风险 | 设计 A/B 降级版本 |

## 五、输出判词

形成当次行为判断时，用一句话说明主目标；待验证目标明确标为假设，后续研究或真实反馈改变判断时回到相关内容修订，不以一次判词冻结全期：

`本活动最关键的行为改变是：让____从____变成____；如果这个行为不发生，活动即使热闹也不算成功。`
