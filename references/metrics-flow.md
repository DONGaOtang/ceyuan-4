# 指标传导模型 + 闭环图

用于本次目标、作用路径、效果测量与系列校准；旧 Step 3/8 是能力索引，按当前问题调用，不把成案或收尾作为开始测量设计的时点。反馈与实际更新沿用 [持续循环](research-and-content-production-loop.md) 五。核心一句话：**结果指标须连接投入、过程、受众所得与可验证的作用假设，不能用并列 KPI 代替解释。**

## 一、四层传导链 × 四维测量

指标从本次目标、决策用途和实际测量能力推导。四层与四维用于发现遗漏，不是每份局部修改都必须填满的表格。

```
投入层 → 中间指标层 → 结果指标层 → 长线资产层
```

需要完整效果设计时，从「数量 / 质量 / 效率 / 成本」检查相关维度；数量不能代替体验质量，效率与成本用于解释资源投入。下表为候选指标，适用且可采集时才采用：

| 层级 | 数量 | 质量 | 效率 | 成本 |
|---|---|---|---|---|
| 投入层 | 预算 / 内容 / 体验 / 人力 | — | — | 合规成本（报批/安保/保险/法务） |
| 中间指标层 | 到场率 / 传播量 / 互动率 | 决策人比例 / NPS / CSAT / 受众匹配 | 停留时长 / 完播率 / 人均互动 | — |
| 结果指标层 | 转化 / 签约 / GMV / 留资 / 融资信号 | 线索质量（MQL/SQL）/ 签约质量（首付比） | ROI / LTV / 成交周期 | CPL / CAC / 毛利 |
| 长线资产层 | 粉丝数 / 内容量 / 关系数 | opt-in 率 / 心智漏斗 / 画像完善度 | 复购率 / 续约率 / 流失率 | — |

传导箭头表示待验证的作用路径，不表示已经证明因果。到场质量、满意度与成交同时升高也不足以排除其他原因；按数据可得性区分履约完成、观察结果、相关信号与增量因果。

> 质量维度增加诊断信息，让待验证的作用路径更具体：区分到场数量、受众匹配、体验反馈等可能因素，并明确需要采什么数据、检查什么替代解释。记录决策人比例和 NPS 不自动证明它们驱动转化；精确的因果归因仍取决于适用的比较设计、数据与证据。

## 二、六条规则

1. **主判据对应本次真正要取得的结果**，通常落在结果指标层；品牌或关系项目可按下表落在资产或中间层，注明它代表的结果及局限。不把成交设为所有活动的唯一结果，局部修稿只检查受影响的目标与判断。
2. **向上追溯**：每个结果指标，说清拟由哪几个中间指标影响（转化 ← 到场质量 + 体验内容），同时保留其他解释，不将路径图当因果证明。
3. **向下追溯**：每个中间指标，说清拟由哪项投入影响（到场质量 ← 邀约匹配 + 内容吸引），再核对实际数据能验证哪一步。
4. **检查后续价值**：目标涉及复访、关系、内容资产或长期品牌作用时，说明可沉淀什么、谁维护、何时复核。一次性服务或局部任务不为填表增加长期指标。
5. **检查相关维度**：按目标选择数量、质量、效率和成本；对影响采用的缺失维度说明原因与决策限制，不为满足配额虚构指标、收入或效率比率。
6. **测量能力核对（防编数字）**：判据须有可取得的记录，先明确谁采、采集成本和范围。只有门口计数而没有可匹配报名数据时，可记录到场计数及限制，不能声称已测到场率。无法量化时用明确的可观察信号与确认人，不将目标百分比直接改成另一种指标而隐去差异。

完整目标设计检查相关层次与维度，局部修改核对受影响路径；无需逐项生成不适用的空记录。每个关键判据说明对象、时间窗、分母（适用时）、责任、实际采集能力及对应内容；数量不能代替内容质量，完成场次也不能代替真实效果。

## 三、作用路径记录

完整策划需要解释投入如何服务目标时，用图、表或短文记录适用作用路径和待验证假设，形式按接手需要选择；已有有效路径直接引用。标题修订、单条文案等局部任务不强建四层闭环图。内部依据保留详细路径，正式方案交主判据、关键驱动和验收方式；约定展示完整路径时再纳入正文或附件。

| 动机 | 链路重心 | 主判据落在哪层 |
|---|---|---|
| 卖货 / 转化 | 结果指标层 | 转化、GMV |
| 品牌 / 占位 | 长线资产层 | 心智、传播、内容沉淀 |
| 关系 / 融资 | 中间指标层 | 到场质量、对接、信任信号 |

- **表达形式**：按可读性使用 Mermaid、箭头、表格或短文，不由输出载体强制四层全图。
- **路径的另一半是回填**：取得数据后，把目标与实际对应到已采用的路径，区分观察到的断点与尚不能解释的原因。

## 四、回填规则（长闭环）

活动结束后，按已采用的路径与可得证据回填；下列为完整路径的检查示意，不要求局部任务补齐所有层次：

```
投入层      实际花了多少 → 花对了吗
中间指标层   实际到场/体验/传播 → 达标了吗
结果指标层   实际转化/签约 → 主判据赢了吗
长线资产层   沉淀了什么 → 心智/关系/数据有没有变厚
```

观察到的断点用于提出补证和改动假设，不自动证明原因。结果指标达标而目标中的资产未沉淀时，先核对资产价值、取得条件与维护责任，再决定是否转移资源。将依据与适用条件写入 `output/case-library/` 或用户指定复盘文件；跑测偏差写入 `output/run-reviews/`，方法论改进建议写入 `output/improvement-log/`；不得把单次结论直接写回方法文件。

## 五、实验结论并入闭环

指标回填回答「结果断在哪」，实验回填回答「原来赌的假设对不对」。二者必须合并看，复盘结果写入 `output/case-library/` 或用户指定复盘文档，不得直接污染 `references/` 方法文件：

```
四层指标结果 → 定位结果断点
实验验证结果 → 定位假设断点
二者对照 → 判断下次该改目标、创意、渠道、执行，还是测量方法
```

例：标题 AB 的某版在已说明样本、渠道和指标上表现更强，但实际到场率低，只能确认所测指标的差异，不能据此确定报名动机或缺席原因。核对受众匹配、真实入口、出行/时段/价格、兑现理解、提醒、天气及数据遗漏等解释，再选择有证据必要性的内容、服务或测量调整；不直接添加保证金或嘉宾投入。

回填字段追加：

| 字段 | 写法 |
|---|---|
| 原假设 | 用户会因为什么产生什么行为 |
| 实验结论 | 哪个版本赢 / 输 / 不显著 |
| 实际表现 | 活动中该行为是否真的发生 |
| 偏差解释 | 样本错 / 渠道错 / 执行错 / 外部变量 / 测量错 |
| 下次动作 | 条件复用 / 当前条件下暂不采用 / 重测 / 换假设；注明范围与重查触发 |

## 六、系列项目的目标与预测

系列项目按 [统筹模块](series-campaign-orchestration.md)“七、测量与每周调整”接入。先明确全期主目标与适用作用路径，再为持续体验、重点场次、轮换内容与线上分支设贡献，不强填四层或要求每场都承担同样的曝光、到访和成交指标。每个关键指标以 `metric_id` 关联 `unit_id`、`session_id` 或全期范围；数据定义、去重与归因口径以 [数据采集规则](data-capture-and-review.md)“二、口径规则”为主。

预测在传播、有效兴趣、参与、到访、核销及复访之间分别建可验证路径，不能把曝光乘一个臆定转化率直接写成到场承诺。预估表至少区分：

| 要素 | 要求 |
|---|---|
| 目标 | 用户要求或策划建议，说明它不是预测或保证 |
| 基线 | 同项目可比时段、往届或适用的比较资料；说明工作日/周末、季节、商户与推广等差异，缺失时标未知 |
| 参数 | 来源、时间、单位、分母、估计范围和适用场景；容量和资源状态不能由公开客流数字替代 |
| 计算 | 展示公式与依赖，例如有效报名×有依据的到场率；结果受同时容量、营业时段与接待能力约束 |
| 情景 | 有数据依据且有助于取舍时建立，数量与差异由本案关键不确定性决定；保守/基准/积极是可选组织方式，不能要求每案三档。改变有意义的敏感参数，保留假设；无依据则交数据需求与条件式方向，不强填数字 |
| 核验 | 由谁、何时、用哪份实绩检验哪项参数，写清仍不能测量的部分 |

分场报名、参与与到访可各自预估，但跨场合计要遵守人次与人数口径；没有跨场去重能力就不能预测全期去重人数或全体访客的复访率。开放街区以实际可采集的人次、在场快照、抽样体验等为依据，不能套预约场次的报名漏斗。

关键信息的置信度、官方自报与增量证据按 [证据规则](anti-hallucination-and-evidence.md)“三点二、按声明性质决定证据要求”“四点五、预测、归因与实际数据”执行。

## 七、真实数据取得后的每周调整

筹划阶段交调整表与预定复核点；取得真实数据后才回填、校准，不给尚未发生的第 1—6 周编造表现。每次更新保留数据截至时间、缺失项、原预测及版本，不将新预测覆盖成原目标。

| 观察 | 先排查什么 | 下一周可检验的调整 |
|---|---|---|
| 曝光高、有效兴趣少 | 人群是否匹配、标题承诺与内容是否一致、入口能否测量 | 以匹配受众测试信息和素材；先验证入口，不能直接扩投 |
| 兴趣或报名高、到访弱 | 出行成本、时段、提醒、名额状态、体验承诺、天气及数据遗漏 | 修入口/提醒/时段或兑现安排，记录作用假设与所需验证 |
| 到访高、参与或核销弱 | 现场体验、排队、权益理解、商户供给及核销链路 | 优先补接待和承接，测实际体验与核销，不据此自动否定创意 |
| 首访成立、已识别复访弱 | 内容是否更新、下一轮理由是否到达、识别覆盖是否足够 | 调整轮换内容或召回；去重能力不足时先修测量 |

每周调整记录“事实 / 可能解释 / 最强反驳 / 调整动作 / 负责人 / 截止 / 验证方式”，并按 [持续循环](research-and-content-production-loop.md) 五定位所需补证任务、实际改稿/改服务、版本及再核验；不是只写下一周建议。连带影响到场次、创作者交付、内容素材、资源、权益和预算时，按统筹模块“二、关联对象与变更”同步受影响项，不复制第二套调整表；变更后的判断不得脱离现场能力。周度校准是运营建议，沿用用户已授权范围，不自动发布内容、追加预算或确认外部资源。

## 八、继续、调整、暂停与恢复（主定义）

在已有测量与调整记录中维护决定，不另建重复预算或日历。发布前检查理解、承诺和当前状态；重点场次后检查体验与可用素材；异常即时处理；周度比较内容贡献、受众反应与资源消耗；收尾按 [条件性复盘](data-capture-and-review.md) 六沉淀经验。这些是本项目适用的复核点，不是每条内容追加审批层。

影响投放、创作者交付、关键素材或接待的决定记录：对象与版本、目标贡献、事实与缺口、观察窗口、其他解释、当前可用容量、后续可变投入与合同约束的 `cost_id` 引用、决定与理由、负责人/授权范围、复核时间及恢复条件。阈值依据项目基线、成本、目标和容量预先约定，必要时允许定性可观察条件；不设统一点击率、播放量或ROI门槛。

| 决定 | 采用条件与动作 |
|---|---|
| 继续 | 当前证据支持目标贡献，入口与兑现可用，投入仍在已授权范围；说明下次观察点，不因曝光上涨自动加码 |
| 调整 | 有可定位的内容、受众、入口或服务问题时，明确改动对象、版本、负责人和验证办法，保留其他解释 |
| 暂停 | 容量/入口/承诺失效或后续投入缺乏依据时，明确暂停哪些发布、招募或追加支出；必要服务通知继续。暂停发布不等于取消合同、已发生费用清零或停止履约 |
| 恢复 | 事先列出需修复并核验的入口、素材、资源/容量和预算条件，由指定负责人依据实际记录确认；仅到了新日期不能自动恢复 |

情境示例（不是实绩）：播放增长、有效兴趣弱、报名入口故障且创作者合同尚未完成时，先验证数据口径与受众匹配，修复入口；暂停导向故障入口的新增招募及无依据扩投，继续必要更正和服务信息。执行核对合同中未交付、可调整、已发生及可能产生的改期费用，创作者按授权协商实际交付；修复后的代表路径可用、接待状态确认、交付/费用变更获适用授权后，由明确责任人恢复相关动作。不能直接得出“创意失败”、追加流量或取消合作的结论。

同一受众的互动下降要同时检查新客/已看未到/已参与/复访等可识别阶段、内容新增价值、重复服务需求、分发和时机；阶段不可识别时标限制。热度突增转入 [接待联动](critical-path-delivery.md) 八点六，宣传采用该处的真实服务状态，不另算一套容量。
