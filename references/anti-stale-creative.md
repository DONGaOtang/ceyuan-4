# 反陈旧审查与破常规组合

本文件解决一个问题：活动内容是否只是惯用流程换包装。按用户价值、实际内容与场域条件审查；下列发散方法帮助找替代解法，不作为每轮必须重选主题或凑组合数量的门禁。

## 一、陈旧活动判定

命中任一条，进入高风险审查；根据真实目标核对后判定，不能只凭形式淘汰：
- 只换主题名，不换用户行为机制。
- 只有视觉包装，没有实际内容、观看/交流/参与方式或受众所得。
- 去掉包装后只剩签到、讲话、抽奖、合影。
- 缺少与本次目标相符的观看、到访、交流或参与价值。
- 没有能说明本次场域价值的内容或动作。
- 有传播目标却没有可转述的内容、观点或画面。
- 对已发现的体验阻力、内容缺口或变化没有回应，只套用现成流程。

判词：
- `通过`：本次用途必要的实际内容、受众所得、呈现与条件已成立；传播和验证按真实任务适用，未知状态明确。
- `修改后通过`：方向有实际价值且缺口可修；当前仍待修改与复核，不提前宣称通过。
- `返回内容开发`：方向有价值，但具体内容、用户所得或承接尚未成立；补相关研究与原型，不默认推翻已选方向。
- `淘汰`：只是旧流程换皮。

本审查在候选生成后的粗筛与成案中使用，保留既有先发散后收敛动作。常规形式不自动陈旧：有具体证据的演讲、内容充足的观看、必要而恰当的仪式可以成立。要攻击的是内容空洞和与需求无关，不是要求每场活动增加反转、竞猜、强制参与或公开传播。独立观看、安静交流和复演均按其真实价值判断。

## 二、反陈旧 7 问

每个创意进入成案前必须回答：

| 问题 | 判断标准 |
|---|---|
| 最像哪种旧套路 | 有可识别参照时指出具体相似处；没有依据时写未知，不编造套路 |
| 用户是否见过 | 若见过，说明新的内容价值或机制差异；必要复演说明服务对象与可达价值 |
| 去掉包装还剩什么 | 若只剩流程名而没有具体内容、证据或体验，退回 |
| 用户所得与进入理由 | 实际内容、理解、关系、体验或适用收益支撑本次任务，不强求排他性或稀缺 |
| 只能现场发生动作 | 按现场/线上/混合场域说明不可被口号替代的观看、理解、关系或行动价值 |
| 适用沟通与素材 | 有传播任务时按已选渠道检查真实内容与权限；闭门/禁拍按实际服务检查，不为填项增加纪要、出镜或公开成果 |
| 研究怎样改变内容 | 指出采用的事实、体验反馈、作品价值或比较判断；反向信号、空白和跨界是可选来源 |

## 三、六类破常规组合

尚未选择方向时，按当前问题尝试适用的组合，形成足以比较与选择的具体候选；已经选定方向则直接深化需要修补的内容、体验或生产条件。六类是方法菜单，不要求每轮生成六类或固定数量。

收敛时按动机与主判据选，不将不同方法硬塞进一个方案。时间结构变化不得用来伪造新内容，权力关系反转不得使核心信息被随机投票隐藏，感官异常不得喧宾夺主。筛下的创意留在过程记录，不扩成正式方案章节。

| 组合方向 | 公式 | 产出要求 |
|---|---|---|
| 用户吐槽反转 | 用户讨厌点 × 反向设计 | 把尴尬、无聊、麻烦、假大空反过来 |
| 跨界移植 | 同一动机 × 不相关行业机制 | 借游戏、综艺、宗教、餐饮、剧场等机制 |
| 平台玩法改造 | 活动锚点 × 平台有效玩法 | 把流行玩法改成该活动独有仪式 |
| 感官异常 | 活动目标 × 非视觉感官 | 用声音、气味、触感、味觉制造记忆点 |
| 权力关系反转 | 主办方说教 → 用户决定/解锁/共创 | 让参与者推动活动发生 |
| 时间结构打破 | 单日活动 → 连续任务/倒计时/分章节揭晓 | 把一次性活动变成可追更过程 |

## 四、创意闪卡增强格式

| 字段 | 写法 |
|---|---|
| 创意名 | 能被目标读者复述并准确指向内容，不设统一字数 |
| 常规做法 | 这个类型通常怎么做 |
| 为什么陈旧 | 用户为什么可能无感 |
| 内容生成依据 | 实际采用的研究、反馈、作品或组合方法；说明怎样改变具体内容，不限于六类 |
| 一句话概念 | 这场活动到底有什么不同 |
| 内容动作 | 在实际场域具体看见、交流、选择、操作或完成什么；不强求互动或现场独有形式 |
| 表达价值 | 有传播任务时说明真实素材与自主表达理由；无公开目标时说明理解、观看或私下沟通所得 |
| 解决的动机 | 对齐已确认的目标行为与真实需要；指标沿用 `metrics-flow.md` 及当前指标主定义，不另造主判据 |
| 待验证假设 | 用户会因为什么报名/转发/留资/到场/购买 |
| 关键核验 | 处理影响当前决定的未知，按可用条件选核实、原型或必要预检，不为闪卡强做AB |
| 最大执行风险 | 预算、合规、供应商、现场秩序等 |

## 五、例子

普通发布会：
- 常规：领导致辞、产品介绍、媒体提问。
- 破局：权力关系反转。
- 新机制：观众投票解锁发布顺序，关键模块由用户选择先看什么。

普通招商会：
- 常规：政策宣讲、样板案例、最后签约。
- 破局：时间结构打破 + 游戏机制。
- 新机制：按区域数据生成“城市战队”，现场争夺独家政策包。

普通年会：
- 常规：领导讲话、节目表演、抽奖。
- 破局：用户吐槽反转。
- 新机制：员工用证据争夺年度叙事权，把“领导总结”反转为“员工审判年度关键词”。

以上仅为发散示例，不是已验证的可执行答案。发布会若以专业判断为目标，投票不得打乱必要证据顺序；招商政策包必须有真实授权，不能虚构竞争与稀缺；年会“审判”是否合适取决于真实组织关系与已确认表达边界。每个入选方向都要补其实际内容、前后关系和完成状态，按当前工作包形成稿件、生产条件和对抗核验；反馈变化时返回相关研究与修订。

## 六、禁止项

- 禁止只给主题名。
- 禁止把跨界行业照搬到活动现场。
- 禁止为了新奇牺牲主判据。
- 高执行难度先检查必要价值、依赖与可行替代；有合理简化就比较损失和成本，无可行兑现路径则退回或淘汰，不强造降级版声称成立。
- 禁止把“视觉高级”当作创意机制。
- 禁止把常规形式等同于内容无用，或把新奇度等同于用户价值；没有真实内容的“创新玩法”同样退回。
- 禁止以互动替代故事、以命名替代节目、以征集占位替代全部核心内容；应交的内容拟案仍由策划完成。
