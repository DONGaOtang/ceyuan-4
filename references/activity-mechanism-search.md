# 活动机制动态检索

本文件用于当前需要的机制研究、内容深化与兑现核查；旧 Step 1/5/6 只是能力调用索引，可按真实依赖合并、并行或返回，沿用 [持续研究与生产循环](research-and-content-production-loop.md)。活动机制有时效性，不能靠固定清单穷举；新的平台玩法、线下互动、票券和游戏化机制须动态检索拆解，固定示例只作启动器。

参与价值与可玩性沿用 [分工交付与体验规则](campaign-deliverables-and-playability.md) 的“二、参与与可玩性”；本文件负责把它转成可研究、可演示、可执行的具体机制。好玩不能仅由积分、扫码、奖品或互动次数证明，也不要求观看型、专业型和闭门活动全部游戏化。

## 一、触发条件

出现以下需要时，按关键机制缺口调用本模块；已有原文、原型或反馈可核其版本后复用。关键词本身不强制新增机制、全套研究或固定数量的互动：

- 用户给出爆款活动、平台帖子、竞品案例，要求拆传播逻辑或复用机制。
- 当前内容需研究或核验实际游戏、判定、奖励、票券/积分、抽奖/兑换、竞价、组队或任务机制；市集、游园名称本身不触发新增游戏、打卡与奖池。
- 用户要求“好玩、出圈、互动、参与感、裂变、留资、转化”，且其实现依赖尚未解释或核验的具体内容/机制。
- 当前内容只剩主题名或视觉包装，需要补实际内容、受众所得或参与方式；观看/专业交流不强改成互动游戏。

## 二、动态检索路径

按当前决策、活动机制与尚缺的关键证据选择检索方向；不相关路径不展开，命中不足、相反材料或新增兑现缺口出现时换词换源补查，不设统一方向数量。

| 目标 | 检索词模板 | 看什么 |
|---|---|---|
| 来访动机 | `[活动类型] + 体验内容 / 参与感受 / 值不值得 / 首次参与` | 用户实际所得是什么，交通、等待、价格和理解成本是否值得；排队不能独立证明价值 |
| 传播/UGC | `[平台] + 活动挑战 / 打卡爆款 / UGC任务 / 话题玩法` | 用户拍什么、标题怎么写、评论在问什么 |
| 转化/留资 | `[行业] + 互动获客 / 体验转化 / 会员活动 / 核销活动` | 如何从参与转到购买、留资、复购 |
| 关系/圈层 | `[行业] + 私享会互动 / 品鉴会机制 / VIP活动` | 如何体面破冰、如何会后跟进 |
| 游戏化 | `积分制 / 闯关制 / 盲盒 / 拍卖 / 排行榜 / 任务制 + 活动策划` | 规则、奖惩、经济系统、风险 |
| 体验与复玩 | `[活动类型] + 新手体验 / 选择反馈 / 分层挑战 / 复玩 / 陪同体验` | 新手如何开始，选择是否改变过程或结果，熟悉后还有什么内容，观看和陪同者获得什么 |
| 失败样本 | `[活动类型] + 翻车 / 吐槽 / 尴尬 / 排队太久 / 奖品争议` | 反向信号和失效边界 |

检索规则遵守 `search-paths.md` 与 `source-access-and-login-workflow.md`：能验证就引用来源，不能验证就标待验证，不得把搜索结果或登录墙内容写成事实。

## 三、机制拆解格式

任何案例机制必须拆成这张表，不能照搬名字。

| 字段 | 要求 |
|---|---|
| 原始机制 | 案例里实际发生了什么，附来源和访问状态 |
| 底层动机与实际所得 | 用户为什么专程来，获得什么具体体验、能力、作品、理解或关系；不能只以主办方曝光、留资目标回答 |
| 开始与退出 | 从看到信息到找到现场、理解第一步要付出什么；等待、支付、社交或公开表达是否必要，中途退出保留什么收获 |
| 内容过程与反馈 | 用户投入什么、作什么选择、何时看见变化；互动型写选择和结果是否不同，观看型写内容揭示与体验推进，不虚造选择 |
| 持续与差异 | 对应首次接触、已看未到、已参与或复访的适用人群，说明其已知/已体验与本轮新增价值或合理重复理由；继续参与、复玩或复访时有什么差异。无需复玩的单次体验说明完整价值，不加无意义循环 |
| 状态规则 | 按实际机制写开始、完成、暂停、退出与结果；涉及成功、失败、排行或复活时才补对应判定 |
| 奖惩系统 | 使用奖励、扣罚、兑换、排行或稀缺权益时写清规则；未使用则不补积分经济系统，仍须说明体验本身的价值 |
| 陪同与可选参与 | 独自来、陪同观看、怕社交、不使用手机或不愿拍摄公开的人如何获得核心体验；活动本身确实依赖设备或团队时，说明理由、限制和可提供的替代 |
| 传播资产 | 哪项真实过程、变化、成果或人物表达值得转述；拍摄、分享是否可选，素材如何取得，不把预期好评写成已发生反应 |
| 数据采集 | 按本次目标选择参与、完成、理解、转化、UGC或留资等适用指标及统计方法；观看和局部机制任务不强加完整销售指标体系 |
| 失效边界 | 人群、预算、场地、审美、合规、执行哪里会失效 |
| 可移植方式 | 换到本项目时保留什么机制，替换什么元素 |

完整机制须能用一轮具体示例演示：从开始条件到参与选择、状态变化、奖励/结果与退出；模拟值标拟案。内容不是只介绍积分名词，涉及票券/兑换时要核对发放、消耗、回收、库存与结束结算的一致性，队列容量必须对应实际单轮时长及并发。

体验演示至少走一次“第一次来的目标用户”路径：看到什么信息、在哪里开始、先做或看什么、何时知道自己的选择或所看内容产生了结果、得到什么、怎么离开。互动型再走适用的不同选择或能力路径，查结果是否只是换名换色；社交、拍摄和手机操作不是核心目的时，另走一次不参与这些动作的路径。没有奖品或明星时，活动主体仍须提供本次承诺的内容；以明星表演为核心的项目须把缺席视为内容变更，不能声称等价替代。

## 四、机制原型快速通道

这些不是固定模板，只是检索和发散的启动器。

| 机制 | 适合目标 | 核心风险 |
|---|---|---|
| 闯关制 | 提升参与率、延长停留、引导动线 | 规则太复杂、排队失控 |
| 积分制 | 多点互动、团队竞争、会员激活 | 通胀、刷分、奖励不够 |
| 银票/筹码制 | 游园、市集、拍卖、游戏化团建 | 经济系统失控、争议判定 |
| 盲盒制 | 稀缺、收集、复玩 | 概率不透明、奖品争议 |
| 拍卖制 | 制造高潮、消耗积分、提高情绪 | 头部玩家垄断、冷场 |
| 排行榜制 | 竞技、挑战、团队荣誉 | 作弊、强者恒强、弱参与者退出 |
| 组队战队制 | 内部凝聚、渠道动员、经销商大会 | 队伍不均、输赢伤关系 |
| 剧本任务制 | 沉浸体验、文旅、品牌故事 | 成本高、理解门槛高 |
| 打卡收集制 | 小红书传播、场地导流 | 只拍照不转化 |
| 诊断/测评制 | To B 线索、教育、医美、专业服务 | 结果不可信、隐私合规 |

## 五、按当前用途核查机制与兑现条件

内容、规则、库存、吞吐和责任按当前任务用途、成熟度与真实依赖同步核查，能现在验证的条件现在核实，不等旧 Step 6。条件式草案可继续提出具体内容和演示；未取得的制作参数记录未知、核验责任、截止及受影响承诺，不要求前阶段提供尚未发生或未验证的未来事实。对外承诺或执行采用所需条件未成立时，只阻对应承诺或采用，独立可做工作继续。检查以下适用项：

1. 用户为什么来，第一步如何理解和开始；已知交通、等待、价格和社交成本是否与实际所得匹配。
2. 用户具体看见或做了什么，获得什么；互动的选择、反馈、难度和结果是否形成实际差异，观看内容是否有完整推进。
3. 新手、熟悉者、独自或陪同者的适用路径是否成立；中途退出、不拍摄或不公开时是否仍有合理收获。
4. 使用奖励时，数量和库存是否支撑承诺；不使用奖励时，体验价值是否依然成立。
5. 单轮时长、并发、等待、现场讲解与反馈速度是否支撑预计需求；高峰或设备失效时如何处理。
6. 涉及判定、兑换或用户争议时，由谁依据什么规则处理；数据由谁记录，漏记怎么说明。
7. 去掉主题包装或非核心明星资源后，主体内容是否仍成立；核心资源缺失时是否已列出真实的内容调整与告知安排。

关键内容或规则不成立时，修当前机制、内容原型或生产安排，核对受影响稿件与依赖，不强制返回旧步骤或重开已选方向。暂未取得的制作参数按本次用途标依赖，不能靠编数通过；实际体验、容量或权益不能兑现时，修对应内容与告知安排。机制、故事和传播角度进入创意文件；岗位、资源、容量、物料、异常处置及预算进入执行文件；具体公开说明、素材和发布安排进入宣传文件，按 [分工交付与体验规则](campaign-deliverables-and-playability.md) 的“一、文件分工”“四、跨文件协同”关联，不把三类内容全复制到同一文件。

系列机制还须对照上一轮实际内容和已发生反馈核新增价值，不能只换标题、颜色或任务名字；稳定识别、新客首次体验与必要服务提醒可以重复，写清对应受众与理由。参与疲劳的判断须核分发、受众、时机和入口等其他解释。点位满额、设备中断或热度突增时，按 `critical-path-delivery.md` 的容量与服务状态联动规则核对报名、候补、宣传口径和真实替代，不现场新增未落实的权益或加场。
