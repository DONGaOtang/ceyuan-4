# AB 测试与最小预检路由

活动行业不总适合严格 AB 测试。按 [持续研究与生产循环](research-and-content-production-loop.md) 的当前问题与依赖先判断是否需要新增验证，再选层级；验证规则沿用 [实验验证层](experiment-validation.md)，不因调用本文件就给全案或每轮增加实验。

## 一、验证层级

| 层级 | 适用场景 | 方法 |
|---|---|---|
| 快速预检 | 当前理解、内容或执行问题可通过小样和走读发现 | 目标受众试读/访谈、整组内容复述、参与路径走读、销售预演；内部评审与真实反馈分开 |
| 准 AB 测试 | 新媒体、线上报名、广告投放、私域邀约 | 标题、海报、报名页、邀约话术、CTA |
| 严格实验 | 有流量、有预算、有周期、有统计要求 | 样本量、随机分流、停止规则、护栏指标 |
| 非 AB 场景 | To G、危机、公关口径、强合规 | 合规审查、stakeholder 预沟通、口径预演 |

## 二、触发规则

本次决定依赖高影响、证据不足的不确定性时，选择能回答它的核查/预检/实验：

- 受众所得、理解或行为承诺尚缺适用证据。
- 新机制或执行条件会改变采用、兑现或预算。
- 要对外提出的效果结论缺少匹配证据，或已有结果相互矛盾。

数量、类型和验证深度由关键不确定性、可比性、成本及实测能力决定，不由活动面向外部、预算档位或体量自动决定。现有适用证据可复用；缺样本、数据、权限或资源时标未验证，列具体下一动作与依赖，继续可做的条件草案，不编实验结果。

可以不做复杂实验：

- 内部小活动。
- 目标低风险且已有稳定历史数据。
- 样本极小，只能做方向性预检。

## 三、不同场景测什么

| 场景 | 优先测试 |
|---|---|
| To C | 海报标题、福利、打卡点、话题名、优惠机制 |
| To B | 邀约话术、议题名、嘉宾利益点、案例背书、会后资料包 |
| To G | 口径审查、利益相关方预沟通、流程预演，不做公开 AB |
| 新媒体 | 实际开头与封面、标题、CTA、参与入口，或整组传播的项目记忆与理解；时长按内容和当前媒介条件确定 |
| 招商赞助 | 权益包、报价梯度、赞助商收益表达 |
| 内部活动 | 员工偏好投票、节目/环节预检、参与意愿访谈 |

## 四、实验设计格式

| 字段 | 写法 |
|---|---|
| 假设 | 因为____，我们相信____会让____人群产生____行为 |
| 验证层级 | 快速预检 / 准 AB / 严格实验 / 非 AB 审查 |
| 对象与比较 | 单项变化、组合或完整路径；说明可回答的问题及不能单独归因的差异 |
| 版本 | 比较版本及共同条件，或单方案的实际内容/流程版本 |
| 样本/渠道 | 在哪里测，给谁看 |
| 判据 | 与决策匹配的主要判断和必要辅助/护栏，允许明确的任务完成与理解标准 |
| 成功阈值 | 提前写，不看结果后改 |
| 失败或不明确的处理 | 修复、补证/重测、条件采用、替代或暂停，以及必要的兑现处理 |

样本数量按问题、可比性、分析要求与资源选择，不设统一人数门槛。内容试读、脚本排练、主持预演、整组传播和完整参与路径都可作为预检；单方案用完成标准，不强行添加A/B。计划、内部模拟、真实受众测试和实际活动结果分别记录。

## 五、硬规则

1. 样本不足只能叫“方向性预检”，不能写“验证成功”。
2. 单变量对照只用于匹配的归因问题；组合比较不能单独归因，多因素实验须有相应设计能力，完整路径/传播组合预检按理解与可用性判断。主定义见experiment-validation三。
3. 未通过、结果不明确或实施失败须有后续处理，沿experiment-validation三；不为形式强建替代活动。
4. To G、危机、公关口径不能随便公开 AB。
5. 严格实验要写样本量、周期、分流、停止规则。
6. 实验结果和最终活动结果不一致时，要判断是样本错、渠道错、执行错、外部变量还是测量错。

## 六、输出判词

- `可直接采用`：验证信号强，风险可控。
- `采用但降级`：方向可用，但规模或表达需收敛。
- `重测`：样本或变量设计有问题。
- `当前条件下暂不采用`：证据显示关键假设或兑现条件不成立，注明范围、原因和重查触发，不从单次结果推导永久禁用。

判词是依据已取得记录的当前采用建议，须绑定样本、原记录、适用范围与限制；不把内部模拟或未执行计划写成真实验证。需修的内容交回持续循环五，保存实际改稿/改服务、相关版本及再核验，不只留下“重测/降级”标签。
