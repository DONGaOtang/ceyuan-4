# 持续研究、创作、生产与反馈循环

用于系列事件、持续内容运营，或用户要求优化既有流程、实际检索/视觉取材/多源分析与持续产出时。按当前任务加载相关节；单项研究、单图取材、轻量活动不自动扩成全案。关键词与研究、视觉和实际生产记录分别辨识；确有独立接手、审阅或维护用途时分件，沿用已有索引连接。单图的来源与观察属于该图说明，不强造额外文件；不同职责的完整正文不混装。

目录：一工作循环与确认；二研究接口；三视觉取材接口；四生产接口（新增价值与受众阶段）；五反馈接口；六验收。

## 一、工作循环与确认

默认工作组织改为以下依赖关系；它们是工作包，不是六次固定回复或审批。旧Step0—9改作能力索引，可合并、并行、复用或返回，不要求每轮从头跑完。研究不只在开头做，审查不只在成案后做；判断、内容与生产条件按实际变化持续接续。

| 工作包 | 判断与实质产物 | 可合并的旧能力 |
|---|---|---|
| A 范围、目标与问题 | 最新任务/读者/交付/阶段、目标人群与实际所得、日期/经营约束、待决定问题及当前授权 | 0判局、2行为、3经营及范围路由 |
| B 研究、取材与对照 | 关键词任务、实际检索和原文/图像观察、多源核对、横纵分析、反证/缺口及决策影响 | 1研究、creative-inputs、来源访问 |
| C 内容架构与原型 | 母题/故事或内容结构、持续/轮换/重点单元、真实参与体验、人物和传播机会、代表场景/稿件 | 4叙事、5创意及体验规则 |
| D 生产、排期与联动 | 场次/资源/唯一预算、采集与制作简报、素材状态、宣传日历、备用内容和接收端 | 6交付、新媒体及制片 |
| E 对抗、核验与交付 | 关键反方与替代解释、实际内容与图像证据、产能/兑现、版本与分工复核，形成可审阅或可接手工作件 | 7审查、8成案、9终审 |
| F 运营观察与下一轮 | 已取得数据/反馈、异常、待验证原因、下一轮研究/内容任务、修改与复核结果 | 数据、指标与系列周调 |

首次建立必要的A—D依据；E贯穿重大判断和交付。运营中由F触发相关B/C/D/E，保留已成立且未变的内容，不把每次更新强制变成重新选主题。用户明确只要研究或图像时，完成该包和对应核验，不强建后续正文。

**按实质决定确认。** 已授权目标与范围内的检索、摘录、观察、条件草案、已选方向深化、代表稿、排期/计算核查和局部修复继续完成，不逐Step暂停。改变已确认目标、主创意、承诺权益、经营底线或已批准预算等需要用户决定的取舍，先做出具体可审阅选项，再仅暂停依赖决定的定稿；独立工作继续。用户要求分步讨论时按其节奏；用户要求完成一版时完成本次范围，并分别标已知、拟案和待核。保存草案不代表资源确认、发布、外联或采购已执行；外部行动沿已有授权。

Token消耗不作为降低需求覆盖、证据范围、内容深度或交付完整度的依据。工具/上下文实际限制用分批、并行、保存与恢复处理，完成尚未读取的必要材料；大量链接、机械全网搜索和重复读取不自动提高质量。研究何时足够由当前关键问题与缺口决定，不按固定平台、案例数或文件行数判定。

## 二、研究接口

### 既有活动资料的接入与适用性

当前提供的方案/Brief、节目台本/现场流程、预算报价合同、运营记录/原始数据/复盘、照片视频及源件，沿用 `source_id` 接入。按本次用途登记：项目与主体、制作/发生日期、版本和确认状态、原文件及页/表/帧位置、实际读取/观看范围、计划或实绩、原始或二手、当时的人群/场地/资源条件、缺页或冲突、素材规格及使用权限。只采用实际读过或看过的内容；未取得的资料记录缺口，不要求每案提供全部类别，也不穷尽无关档案。

旧计划人数不等于实到，旧报价、阵容、场地和权益不等于当前确认；往届自报复盘不自动证明增量。采用项写明“本轮保留/改写/弃用/待核—理由—影响的判断或 `unit_id/session_id/asset_id`”。已确认的主张和方向直接接续，发生变化的条件重新核查。照片视频能支持的观察与不能支持的结论分别记；可制作素材仍按三、四核验规格、权限、内容和产能。既有资料由此成为新判断的依据或反证，不能只列文件名。

### 从决定拆到关键词与路径

先写本轮要决定什么、哪种证据可能改变它，再拆检索任务。完整系列研究检查以下适用面，局部任务只展开相关项：

| 拆解面 | 关键词与问题来源 |
|---|---|
| 对象身份 | 地址/城市/项目及运营方别名，活动、作品、创作者、租户正式名与旧名 |
| 时间与场景 | 当前/历史年份、运营周期、节假日、工作日/周末、室内/开放街区/夜间 |
| 人群与选择 | 本地/通勤/家庭/游客等实际客群；愿意来、看、做、分享、再来的具体所得与阻力 |
| 内容与机制 | 持续资产、复演/轮换、创作/表演/观看/学习、投稿/揭晓/商户兑现及素材生产 |
| 履约与反向条件 | 排队、服务、噪声、设备、容量、费用、改期、兑现失败、投诉；与所研究机制相关才采用 |
| 表述与语言 | 中文同义/行业词、项目原语言、英文机制词；译名须回到原名，搜索歧义用城市/日期/排除词消除 |

每个研究任务把关键词变成**实际可执行的查询**：对象+机制/问题+适用时间/地域；根据命中补别名、站点限定、反向词或语言。不能只交“去小红书、查国外案例”。正式日期/规则优先主办原文，体验优先原参与者记录，技术/经营条件找其有权或原始资料；平台先后由声明决定，访问动作由 `source-access-and-login-workflow.md` 主定义。

行业入口与替代路径以 `search-paths.md` 为主定义；目录外能够回答当前问题的新来源可纳入并核验，不把网站名当白名单。公开资料优先；账号后台、付费内容、甲方数据和现场反馈在实际可获时扩展，入口存在不代表内容已读或权限已取得。不同来源各自支持的身份、机制、个人体验、总体口碑和效果判断不能互相替代。

### 实际动作与多源核对

研究记录至少能恢复：任务/查询原文、工具或站内入口、时间与筛选、执行状态、命中对象、进入原文的具体范围、实际摘取的事实/观察、失败及换路、剩余缺口、下一动作与对判断的影响。站内滚动/筛选、打开原文、查看评论、PDF页/视频帧与工具返回摘要分别记录；计划中动作不得写成已执行。搜索排名、摘要、转载数量与封面不代表完整读取。

来源事实用现有 `source_id` 绑定原始URL/文件位置、发布与发生时间、访问范围、生产者/是否同源、证据性质与限制。对关键策略、总体口碑、效果和争议判断主动寻找独立与相反证据；同稿转载不互证。可信官方原文可验证其公布的日期/机制，不因多源扫描强迫凑第二份；主办自报规模不升级为增量。本轮未发现负面、没有访问到评论和机制推演的失效条件分别记录。

覆盖表按“问题—已取得—仍缺—影响—补查/条件推进”复核：身份/场景、内容/周期、人群价值、服务/资源、传播/素材、经营承接、效果证据与反向条件。范围不适用的说明原因；可发现且会改变当前判断的缺口继续换词换源；当前权限/公开资料不能解决的保持未知并提出核查责任。重复命中只增加转载时改路径，不以“够了几篇”结束，也不无目的追求穷尽网络。

### 横向与纵向产物

**横向**比较同档期/相近条件的项目或机制：服务人群和所得、进入成本、周期、持续/轮换结构、参与动作、素材如何更新、创作者任务、商户接收、服务与资源、证据强度与失败边界。不同预算/场景/人群不可比时标差异，不靠漂亮照片排名。

**纵向**追一个对象的演变，或追一次系列的开始—发展—兑现—后续：什么内容在何时出现、用户先知道/做什么、下一节点需要哪些真实材料，规则和人员如何承接；有原始资料才写历史因果，没有只提出假设。每个采用的判断给“保留什么、改变什么、为什么适合、在哪种条件下失效”，并关联将改变的 `unit_id/session_id/asset_id`。分析须出现事实对照和具体决策，不以“横向/纵向”两个标题代替实际工作。

## 三、视觉取材接口

参考图是研究与创作材料，现场照片、设计效果图、示意/分镜、作品局部、规则/导视图和视频帧分别识别。真实视觉判断需要实际看见对应图/页/帧；正文抽取、搜索摘要和图像URL只能证明其明确支持的部分。

每个采用的视觉参考沿既有 `asset_id` 或研究资料索引登记：`source_id、发布者/作者及可知日期、原页面/官方图或PDF页/帧位置、图像类别、实际查看方式/范围、摘取载体或未取得状态、实见观察、借鉴用途、不足/不可推断项、关联单元与素材`。局部裁取保留原图位置/裁取范围；不把不同图混作一张现场事实图。

优先使用工具可原生显示的实际图、浏览器截图、PDF页截图，或可获授权的项目素材。用户需要可离线/可编辑的取材册时，确有可用图片才将其与来源说明装入取材文件；只交链接要明说尚未形成摘图文件。公开图的观察/引用不代表生产素材授权或高清原件已取得；相关权利和可用规格进入制作条件。工具限制时提供实际可检查的原页位置及观察范围，缺关键图则保留缺口；不下载远程媒体来绕过显示限制，不用生成图冒充案例原图。

图像分析回答具体问题：入口怎样让人理解、内容怎样被看见/听见、动手/观看空间怎样组织、用户选择或成果怎样呈现、品牌与内容如何关联、素材怎样让线上看懂。照片不能证明客流、满意度、尺度、设备参数、预算或施工可行性；这些另核。借鉴对象可以是信息结构、动作呈现或空间关系，不能只有“高级、好看、沉浸”。

具有独立审阅或维护用途的视觉取材册与检索记录分别成件，使用相对链接连接；单图任务可在其图注保存该图的来源与观察，不另强建检索文件。创意只摘采用的视觉方向和解释，不塞整个参考库；生产简报另写本案所需画面、对象、动作、上下文、规格和资源依赖。原创示意图明确为拟案，不能抵消缺失的案例核验。

## 四、生产接口

### 持续原料与内容变化

每个核心持续单元说明原料从哪里来、如何更新、何时可用、谁核实并处理：项目事实/作品/人物本领，持续场景的真实过程，轮换节目/主题，经过同意的参与成果，适用的商户服务，真实问询/反馈及已备教学解释。哪些是有限库存，哪些依赖现场发生，哪些会枯竭或不能公开分别标注；不以“每天发”替代原料设计。

持续产出不是要求天天新主题。共用母题可通过真实新成果、人物/视角、过程、解释、观看/服务和下一节点更新；同稿换标题、多尺寸导出、重复倒计时与新内容分别计，不把再剪一版当新事实。策划同时保护现场体验，不让采集耗尽辅导/接待能力。

### 新增价值与受众阶段（主定义）

审核关键连续内容时，以本轮实际受众可能已经接触的内容为参照，在既有内容机会或日历中记录：`目标受众及已知接触范围 → 此前已知/已体验 → 本轮新增事实、结果、观点、解释或服务价值（或必要重复理由）→ 为什么在此时出现 → 实际稿件/素材及下一步`。接触范围不可识别时标假设，不能把全网受众假定为都看过上一轮，也不能从多账号曝光直接得到去重人数。

并排读取相关轮次的实际文案或脚本，暂去标题、封面和尺寸差异，指出正文中新增价值落在哪里。若只有重复的“好玩、热闹、快来”，合并、改写或改变发布任务，并回写日历和素材Brief；不能仅在审查表填“有创新”。复演服务新观众、地点/规则提醒和稳定项目识别可能有价值，保留时写清服务对象与当前需要，不强求每条信息全新。

按可获得信息区分首次接触、已看未到、已参与和复访等本案相关阶段，检查其信息、规则和体验负担及下一轮所得；这是受众理解方式，不是必须建成四个人群包或收集额外个人数据。首次接触需要独立看懂；已看未到先核对真实阻力；已参与者可获得结果与后续；复访承诺须有新增价值或如实说明的可达便利。重复场次可以继续服务新观众，不设统一曝光上限或更换天数。

互动下降不直接证明疲劳。将内容重复、分发变化、受众匹配、时机、入口和服务问题作为竞争解释，按 `metrics-flow.md` 的实绩诊断与运营决定核对；没有实际接触和反馈证据时只提出待验证原因。可用目标用户反馈检查下一轮是否有价值，内部角色模拟单独标识，不能称真实接受度测试。

### 从研究结论到实际稿件和制作

选一项采用的研究/视觉观察，写明它怎样进入本案内容，并形成对应的代表场景、提示语、标题/段落/脚本或素材Brief；用户要求全量时完成约定全部内容。纯研究任务只给内容影响与下一动作，不强写成稿。样稿绑定事实和状态，事件未发生不能写既成作品、金句、观众反应和成果。

生产表沿用宣传日历/素材交接与执行资源占用接口，增加本轮需要的内容成熟度与缺口，而不复制第二套日历、资源或预算：

| 生产对象 | 必须可定位的条件 |
|---|---|
| 内容机会与采用决定 | 关联研究/视觉来源、受众阶段与已知接触范围、此前已知、本轮新增价值或必要重复理由、为何此时出现、所属单元/场次、采用/舍弃依据 |
| 素材与Brief | 对象/动作/场景及必保留前情、取得时间和方式、已持有/待采集/失败、可用范围、责任与依赖 |
| 原稿/制作/审核 | 实际稿件或源件位置、版本与状态、制作/核实/审核负责人、截止；未生成音视频与已写脚本分开 |
| 节点与接收端 | 日历中的日期/账号/用途、用户下一步、真实入口/容量和回应能力、发布状态与更改处理 |
| 储备与备用 | 哪些实际材料已核、可用、符合下一节点；哪个现场依赖失效会断供、用哪份真实备用内容替代及是否会改承诺 |

储备按已约定更新节奏和生产时滞安排，不设所有项目统一天数/条数。待采素材、未核事实、无授权内容和仅有选题不计为可用成品；既有可用示范、服务说明或过程解释可做备用。未来活动取消，备用应如实解释变动与剩余价值，不继续宣传已无法兑现的场次。无必要公域发布的日子可以研究、制作、采集或服务；周期不断档不等于所有平台天天发。

内容、传播与执行各自维护其专业正文，主维护位置、ID/版本与变更沿 `campaign-deliverables-and-playability.md` 四及 `series-campaign-orchestration.md` 二。制作工时、设备、人手、审核与费用回执行主账/排期，不能只增加内容数而不增加生产条件。

## 五、反馈接口

轻量监看按实际内容频率/风险/采数能力进行；系列取得真实资料后按周及重大事件复核，短期素材或权益异常及时处理。反馈任务不只等活动结束：补给前预检、场次后真实问题、当前缺料、入口受阻、人物/天气/设备变化都可触发下一轮。

将本轮事实、待验证原因和推演分开，再生成一个具体更新工作包：`观察/原始记录 → 与目标或承诺的差异 → 最强替代解释/反证 → 要补的研究问题 → 内容/素材/服务修改 → 负责人和截止 → 受影响版本 → 下一次怎样判断`。没有实绩时只能做桌面情景或计划预检，不能虚报周调效果。

审核节奏嵌入现有工作：发布/招募前查理解、承诺与当前接待信息；场次后查真实体验和素材；异常时同步受影响入口与服务；周度检查人群、内容贡献和资源投入；收尾记录适用条件与再核验触发。继续、调整、暂停、恢复及费用/履约判断引用 `metrics-flow.md`，接待状态联动引用 `critical-path-delivery.md`，条件性经验引用 `data-capture-and-review.md`，不在本文件重复维护指标、预算或状态表。

例如传播强而到访弱，先分受众、内容所得、时间/交通/价格、真实入口和容量等原因，查对应证据；不是直接曝光换到场或再加达人。稿件不够时先区分没有内容原料、未采到、不能用、工时不足或审核延迟，再调整该环节；不是靠复制日更选题填空。

每轮对抗先写当前方案最强版本，再攻击决定性的假设、证据独立性、图像误读、用户价值、内容供给、服务产能与跨文件承诺。关键问题给具体修补和重新检查；新事实推翻旧结论时修改主定义和受影响工作件。完整大案覆盖适用风险，局部更新聚焦本轮新增或变化的风险，不为相同结论重复全量审查。

## 六、验收

对本次实际范围检查：

1. 关键词和实际检索记录能追到已读原文/已看图，执行、计划、失败与未读区分；关键多源判断不以同稿转载互证。
2. 横纵分析有实际对象、对照、时间变化、反方与采用决策；缺证据的历史因果、总体口碑和效果保持未知。
3. 已声称摘取的图可实际查看、能找到原位置且有具体用途；图类别和事实范围准确，链接不冒充已交摘图文件。
4. 从一个研究/反馈结论能追到本轮实际内容或明确范围内的影响；持续全案能追到素材、制作、节点、接收端、产能与备用，而不只日历标题。相邻关键稿件能指出相对于目标受众的新增价值或必要重复理由，空转后已有真实改稿和排期更新；受众阶段与疲劳推断不冒充已知事实。
5. 实际发生一次反馈/资源变化时，能定位新研究问题、具体改稿/改服务、版本和再核验；无数据用明示桌面情景，不称实测。
6. 可用原料、代表稿、全量成稿、源件、资源已落实、用户决定、外部已执行和效果已测分别验收。分文件不破坏主值唯一，深度不因节约Token降级。

可用语料、案例与图片仍按具体项目验证，真实接受度和增量效果不由方法表或自评分证明。检验失败修实际内容与依赖，不靠增加步骤、平台名和文件数量判完成。
