# 创意总监质量门禁

本文件用于 Step 5 创意机制、Step 8 成案和 Step 9 终审。它解决一个问题：策略正确、执行完整，不等于创意成立。创意总监要判断的是这个方案有没有被记住、被选择、被拍板、被传播和被执行成作品的能力。

## 零、使用边界

创意质量门禁只用于**收敛、成案和终审**，不得用于发散阶段提前压制创意。

未选方向时分开发散和收敛，按实际问题执行：

1. 先按适用的交叉方法生成足以比较关键差异的候选，不边生成边以评分删除。
2. 再用实际所得、经营判据、专属性、持续内容原料和生产条件收敛，不设统一候选数。
3. 最后才用本文件判断主创意是否值得进入成案。

禁止一边发散一边套本文件的八问。那会把创意磨成“正确但无聊”的平均方案。

主方向已经选定或本轮只需更新内容时，直接深化并核验本轮变化，不强制重新发散或重新选题。持续产出按 [研究生产循环](research-and-content-production-loop.md) 四、五检查真实原料、变化、产能、备用与反馈回接；新奇和素材数量不能代替这些条件。

## 一、触发条件

命中任一项必须加载：

- 用户要求创意、主题、Big Idea、传播爆点、出圈、好玩、差异化、提案感。
- 乙方提案、比稿、招商赞助、老板过会、高预算、品牌年度项目。
- 活动依赖视觉、命名、打卡、UGC、社媒传播、主视觉、现场装置或用户自传播。
- Step 5 生成创意闪卡，或 Step 8 输出正式方案。

不命中时也可作为轻量自检使用，但不要用它替代 Step 2 行为改变、Step 3 经营模型和 Step 6 交付系统。

用户明确要求高可玩性、来访动机、人物形象或正向扩散时，同时读 [分工交付与体验规则](campaign-deliverables-and-playability.md) 的“二、参与与可玩性”“三、传播与人物”。本文件负责审阅内容是否真正成立；不增加审批阶段，也不把互动、剧情和公开传播设成所有项目的统一配额。

## 二、创意质量八问

每个进入成案的主创意必须回答：

| 问题 | 合格标准 | 不合格信号 |
|---|---|---|
| 核心内容能否复述 | 目标读者在实际接触条件下能准确讲清；专业内容可保留必要解释 | 只记口号，误解实际内容或条件 |
| 是否有专属性 | 换成别的品牌/城市/客户就不成立或明显变弱 | 谁都能套 |
| 是否有行为张力 | 内容使用户产生本次目标所需的观看、理解、判断、行动或关系变化；用户实际所得及愿意投入的理由能解释 | 强迫互动；看听内容空洞；主办方获益代替用户价值；扫码、积分和奖品掩盖空内容 |
| 是否有现场唯一性 | 在已确定的现场/线上/混合场域提供具体证据、身份、仪式或体验价值 | 只有一张氛围图；线下聚集没有必要价值 |
| 是否有传播画面 | 在本次允许的传播范围内，关键画面、观点、真实变化或成果可准确转述，能说明观众为何可能主动表达 | 画面漂亮但无信息；预写自然好评；官方口号代替用户可表达内容；为闭门内容强加公开传播 |
| 是否有资产延展 | 能转成此次实际需要的内容、视觉、现场或传播资产 | 只有一句主题，约定的资产无内容支撑 |
| 是否有审美适配 | 符合行业、价格带、人群身份和场地质感 | 网红化、廉价化、口号化 |
| 是否有执行抓手 | 执行团队知道做什么、采购什么、怎么验收 | 需要二次脑补 |

八问不等于八种必加环节。观看型活动可以靠表演、内容揭示和审美体验形成价值；专业会议可以靠证据和判断，闭门交流可以靠可信关系与后续约定。按原问题完成判断并写出本次依据，不要求所有活动投票、共创、拍照、留资或出圈。对确不适用的公开传播/线下场景要求写明范围与替代证据，不能简单以“不适用”略过内容价值。

## 三、Big Idea 质量标准

Big Idea 不是活动主题，也不是口号。它必须同时具备：

| 维度 | 标准 |
|---|---|
| 问题性 | 回应一个真实矛盾，不只是表达祝福 |
| 行动性 | 能长出与目标匹配的内容、呈现动作和受众体验；有传播目标时再接传播动作 |
| 专属性 | 和品牌/项目/人群/城市资产绑定 |
| 延展性 | 能支撑本次承诺的核心内容及必要表达，不为凑模块拆碎单一体验；系列活动须说明各单元怎样共享和改变母题 |
| 可证明性 | 能留下与目标相符的证据，例如内容样稿、演示结果、作品、关系后续、签约、反馈或经允许的影像 |

推荐表达：

```
「主题名」—— 让____通过____内容与____动作，获得/完成____。
```

禁止表达：

- 只堆形容词：高级、年轻、沉浸、共创、焕新。
- 只写情绪祝福：一起向上、共赴美好、一路同行。
- 只换皮：把普通签到、讲话、抽奖、合影换成古风/科技/露营/艺术包装。

## 四、创意资产包

正式方案或乙方提案不能只交一个概念。按需输出创意资产包：

| 资产 | 最低要求 |
|---|---|
| 命名系统 | 活动名、分区名、互动名、奖项/权益名，口径一致 |
| 主视觉方向 | 视觉关键词、参考方向、禁区、核心画面，不伪造设计成稿 |
| 核心创意表达 | 主张、关键现场表达/主持口播、代表性标题方向；邀请及平台完整稿由宣传文件维护，现场执行引用所需稿件版本 |
| 内容与人物结构 | 主要单元实际呈现什么，内容如何开始、推进和结束；有故事时写故事开端、承接与结尾，人物凭什么本领和选择推动内容 |
| 现场拍摄点 | 确需拍摄时列支撑内容的必要画面、人物动作、项目证据及权限；数量由实际内容和采集能力决定 |
| 社媒内容钩子 | 仅对已选渠道写目标受众、内容角度与实际表达，按本案材料核对平台惯例 |
| 执行转译 | 每个创意资产对应现场物料、人员动作、交付时间和验收方式 |

整合系列大案按 [分工交付与体验规则](campaign-deliverables-and-playability.md) 的“一、文件分工”“四、跨文件协同”交付：创意文件维护主题、故事与内容推进、人物角色、现场表达、潜在传播角度和可用资源的创意用途；宣传文件维护平台议题、节点、账号、达人任务、具体稿件及日历；执行文件维护实际场次、岗位、资源状态、技术与异常处理及唯一预算。创意文件可以写“需要一名能完成现场示范的专业创作者”及匹配理由，已联系/已报价/已确认等状态引用执行记录，不另造一套资源名单或预算。单项需求只交所需模块，不强制三份文件。推导依据、被否方向和审美争议继续进入思考过程文件。

按本次目标选择资产，不为媒介齐全扩展交付。资产清单之后须能看到本阶段需要评审的实际内容：核心主张不能只有“待撰写”，关键传播稿不能只有选题名，主要内容单元不能只有活动标题；需要讲清作品、演示或论证的项目按 `narrative-and-concept-delivery.md` 展开。选定方向的代表文案、场景/分镜或演示段落须写成可审阅拟案，涉及真实事实和外部资源的部分单独标状态。

完成等级不得混写：视觉关键词是方向，文字分镜是简报，脚本提纲是结构，实际图片/完整脚本才是相应成稿。用户要可生产资产时，按其规格与范围交付；不能仅通过更名或导出文件格式宣称已完成。主张、内容、动作、传播与执行沿用同一名称和事实，不能在传播里许诺现场不存在的体验。

## 五、系列项目创意校验

触发系列事件统筹时，按 [系列事件统筹](series-campaign-orchestration.md) 的“四、系列活动与邀请”“九、联动验收”核对：母题怎样在本案实际内容中发展；新内容与同作复演是否如实区分；观众有什么首次参与的理由，承诺复访或继续参与时是否有具体价值。有线上任务才按“五、线上分支与逐日内容”核主张在对应内容/服务中能否兑现，有线下兑现再核实际现场。复演可以满足不同日期和人群的需要，不能只因内容相同判失败，也不能把换名、换色写成新作。

有线上传播任务时，代表稿须能展示核心分支的真实信息、参与价值与适用后续承接；约定逐日选题时须有可取得的素材或可执行的生产安排。无对应任务不为创意门禁强建稿件、账号或日历。未知艺人、费用、档期和场地条件保持相应状态，创意可审阅不等于资源已确认。

## 五点五、参与体验与正向扩散复核

要求高可玩性时，按 `activity-mechanism-search.md` 走一次目标用户的完整体验：第一次来的人无需长篇规则能否开始，互动选择怎样改变过程或结果，反馈是否及时，不同能力与陪同观看者是否有所得，复玩或复访是否有内容差异。不愿社交、拍摄或公开的人仍应获得本次核心体验；活动确需团队或设备时写明适用边界与可行替代。不能用增加扫码、积分层级或奖品种类代替这些答案；观看型内容按实际揭示、表演或论证推进评价，不添加虚假的互动。

要求正向爆点或人物形象时，用一项代表场景说明“人物真实会什么—面临什么内容任务或选择—现场发生什么可见变化—观众有什么自己的话可说—能取得什么证据”。人物角色与创作剧本可设计，真实技能、履历、成绩、现场反应和引语须核验；拟案不得写成自发事实。即使短视频没有扩散，现场内容也须兑现承诺；品牌通过什么具体内容被记住要可解释，不能只凭末尾露出标识。

成案复核用本次适用的反例：没有非核心明星时主体是否仍成立；第一位新客走完后具体带走什么；怕社交或不愿上镜者是否能完成核心体验；关键拍摄失败时还有什么真实可用素材；官方已发内容而用户没有表达时，先查是否缺少自己的观点、成果或安全且方便的表达入口。检查结果用于修内容与交接，不承诺爆款，也不靠安排观众夸赞通过。

### 项目与地点记忆（主定义）

当目标包含项目认知、商业目的地或到访时，检查实际传播组合中的人物/活动/项目/地点关系：通过哪些真实场地、作品、商户、人物行为或服务信息，使受众理解这件事为什么在这里、现在到访能获得什么。每条内容可以承担不同任务，不要求逐条塞满标识和地址；但组合及参与入口应能完成本次项目识别与到访理解，不能只有明星或装置记忆。

使用实际文案、样片或原型，在接近预期接触顺序的条件下预检；先不提示答案，记录目标读者记住了什么、能否说出项目/地点、理解的可获内容和下一步，再查遗漏与误解。反馈必须记录实际对象、材料版本、接触范围和所说内容；没有可用目标用户时只做内部桌面检查，标真实反馈待取得。内部模拟、少量预检与正式品牌认知测量分别报告，不据此宣称品牌提升或增量到访。

只记住人物或活动时，回查内容里项目的实际作用、入口是否清晰和信息组合是否完整，修改具体稿件/场景/服务信息后复核。不能只加Logo就判通过。测量定义与数据引用 `metrics-flow.md` 和 `data-capture-and-review.md`，宣传稿件仍由宣传工作件主维护。

## 六、创意辅助评分

需要比较候选或解释短板时，可选择与本次目标相关的维度做有据比较，也可不用评分。可选维度包括问题定义、内容可复述性、项目专属性、受众所得、适用传播、审美适配、经营贡献和执行转译。使用评分则在比较前说明尺度、维度及权重的项目依据；不沿用固定百分制或权重，也不看到结果后调整权重以偏向某案。

先检查本次必需内容是否真实存在、核心依赖是否准确标注，再比较。“现场行为”可以是有效观看、论证或关系建立；无公开传播任务不强设传播得分。记录依据与置信度，不设通用放行分数线。核心内容空白、虚构证据、用户指定文件实质缺失不能靠其他高分抵消；分数是本次审阅判断，不是实际市场效果。Step 9 以本次用途所需的内容、证据、数值一致性、关联关系及执行条件作判定。

判词依据实际缺陷：方向成立且本次用途要求已满足，可作为提案主创意；有明确可修缺口，列出修复内容并复核；关键机制或依据不成立，回到相应步骤修正。高分不能抵消关键失败，低分本身也不能代替具体退回理由。

## 七、创意总监反问

当前用途的成案复核按实际读者与任务使用下列问题；纯内容、纯线上或不采购项目不强造老板、发布与采购角色：

1. 客户老板会复述哪一句？
2. 用户会记住或在允许范围内分享哪一项具体内容？
3. 传播或内容团队会提取哪一个准确的场景、观点或证据？
4. 本次需要执行时，接手者是否知道具体准备或操作什么，以及条件和验收？
5. 去掉视觉包装后，这个机制还剩什么？
6. 换一个品牌照抄，会不会仍然成立？如果成立，专属性不足。

再用主要内容单元核对上述答案：删掉主题名、视觉包装和主持串词，读者是否仍知道看见什么、发生什么变化、为何如此接续。答得出一句主张却找不到正文承接，仍不通过。
