# 系列事件营销统筹

本文件定义系列项目的关联、阶段交接与验收；专业方法仍由研究、报名、预算、传播、互动和制片参考负责。只读当前阶段对应短节。编号用于定位真实内容，不替代内容说明。按 [持续研究生产循环](research-and-content-production-loop.md) 一、四、五组织工作，旧Step标签只是可合并/复用的能力接口；方法论维护与已有方案修订沿用原边界。

目录：一触发与阶段；二关联与变更；三项目研究；四活动与邀请；五线上与日历；六资源预算；七测量调整；八工作簿；九验收；十机制参考。

## 一、触发、范围与阶段接入

满足明确的多周统筹需求，或跨期多个单元/场次、轮换与持续运营需要共同策划时启用。仅把单场活动预热一个月、同一天拆成多个环节，不自动启用。商业地产地址研究为条件分支；其他行业按真实项目对象研究，不硬套商圈、租户或核销。

Step 0 登记筹备、预热、活动运营、收尾的实际起止、时区及待确认边界；这些时段可以重叠。一个半月不固定等于45天，不能把预热无声塞进运营期。日历覆盖约定范围，先用相对日期时标暂定，确认后转换并复验。实际涉及线下与线上各职责的整合大案，按 [分工与体验模块](campaign-deliverables-and-playability.md) 一分别交线下创意、线下执行（含唯一总预算）、宣传方案；研究、到访运营和测量按独立使用需要扩展，不再默认统一客户总案和万能工作簿。局部/方向任务只交本次范围内的工作件。纯线上、纯线下或闭门系列同样按真实任务启用相应短节；线上分支、公开宣传、到访与商户承接均须有对应任务，不由“系列”标签强加。实际承诺的内容、服务或交付即使没有线下场地，也须核对兑现端与能力。

| 专业能力索引 | 本模块接入与阶段产物 | 专业依据 |
|---|---|---|
| Step 0 | 明确是否系列、周期边界、研究对象、读者用途、已知资料与高影响缺口 | triage-router、scope-and-commercial-boundary |
| Step 1 | 项目诊断、口碑样本、案例机制与来源索引；说明每个发现影响什么判断 | search-paths、source-access-and-login-workflow、anti-hallucination-and-evidence |

| Step 4—5 | 母题、系列内容与复访价值、单元/场次结构、资源类型及必要候选比较；有线上任务才设计核心线上分支 | narrative-and-concept-delivery、creative-inputs；有传播任务时new-media-campaign |

## 二、关联对象与变更

在同一项目中维护以下稳定标识，按工作表需要使用，不强制每行塞入所有字段：

| 对象 | 标识与关系 | 变更约定 |
|---|---|---|
| 内容单元 | `unit_id`，母题下实际的作品、体验或节目；有实质介绍、版本与价值 | 内容深化记录版本；独立新内容另设单元，复演或改名不能冒充新作 |
| 实际场次 | `session_id`，关联一个或多个 unit_id，记录日期/起止/点位/人数/状态 | 复演使用不同场次；改期保留场次身份、旧值与原因；取消保留记录并停止相关承诺 |
| 内容资产 | `asset_id`，文稿、脚本、影像或发布内容，引用单元/场次、版本与素材状态 | 现场事实、嘉宾、日期或规则变化后，标出受影响资产待复核，不能继续以旧稿发布 |
| 证据、费用、资源、指标 | `source_id`、`cost_id`、`resource_id`、`metric_id`，供相关表索引 | 共用对象一次登记、多处引用；来源与专业口径仍在所属参考和工作表定义 |

场次区分拟定、待确认、已确认、取消、已发生；改期另记录影响与复核状态。资源、候选与报价使用其真实状态，写出拟案不等于资源落实。预期效果不与已发生结果混列。

变更记录至少写对象、版本/日期、旧值、新值、原因、来源、受影响产物、负责人及复核状态。改动场次后沿关联检查邀请/履约、内容与入口、通知、素材、资源占用、预算、指标窗口、规则及替代；标记真正受影响项，保留不受影响结论。已发布材料需要纠正/通知时列待执行动作和授权状态，不冒充已通知。

## 三、项目研究与案例迁移

既有方案、记录、复盘与影像按 [持续研究生产循环](research-and-content-production-loop.md) 二的接入规则识别版本、实际读取范围、计划/实绩与当前适用性；不把旧资源或效果直接写成本期确认。

适用项目先连接营销策略：用可证项目资产、目标人群与替代选择、具体到访/参与所得、经营约束说明定位，区分项目长期定位与本期活动主张。将本案需要取得的行为分配给持续单元、重点场次、轮换与线上内容，说明哪个内容负责发现/理解、到访、停留参与、商户或其他接收端、再次参与，按真实目标选择。每项营销任务须追到实际内容、渠道任务、行动入口和兑现端；不要求每场同时曝光、引流、成交、复访，不重复建立预算或指标主值。

商业地产从地址出发按需完成：

1. **项目身份与空间**：核对同名/别名、具体位置、商业类型、运营主体、公开营业与交通信息、可见场景及可用点位线索；公开图片不能证明当前尺寸、结构、消防容量、用电、噪音边界或可租用状态。
2. **商圈与人群**：按实际交通和生活路径分析周边居住、办公、学校、旅游等关联及竞争项目；说明观察、来源和推断，研究范围按项目与可达性确定，不机械套固定半径。地址不能推出真实客流、消费力、会员结构或人群比例。
3. **商业与历史**：租户组合、招商/经营诉求、商户权益承接、历史活动与运营季节；客流、客单、核销、资源合同、场地容量等内部数据列甲方/物业需提供，不猜值。
4. **口碑样本**：记录平台、关键词、时间范围、项目是否匹配、已读样本/评论、访问限制、正反体验和反证。排队、交通、服务、体验、消费等按真实内容归类；抽样不代表全部消费者，官方传播和付费体验不冒充自然口碑。
5. **策略结论**：输出哪些问题活动能回应、哪些经营/服务问题需先解决、何种人群收益值得验证、项目可用的独特资产、限制和待确认项。每条判断回到来源或明确假设，并说明影响后续哪个单元/取舍。

案例按本地近似项目、国内同类、国外可迁移机制检索；不足时扩大条件并说明差异，不设固定数量配额。案例卡记录周期/场景/人群、持续资产、内容更新与差异、参与动作、线上分支、素材、创作者角色、商户承接、成本与资源条件、结果口径、来源日期/访问状态和可迁移边界。公告只能证实公布内容；复盘自报、商户个体说法、独立测量、策划推断分别标注。

来源专业规则引用 [anti-hallucination-and-evidence.md](anti-hallucination-and-evidence.md)，访问/登录按 [source-access-and-login-workflow.md](source-access-and-login-workflow.md)。主动找反证；已搜范围内未发现负面或证据不足时保留记录，不编造负面、平台数据或链接补表。完整证据保留在内部索引，面向客户仅交约定依据摘要。

## 四、系列活动与邀请

先确定总主张、持续体验、重点节点、轮换内容、参与路径及各场独立价值。持续装置、周末事件、平日内容等是可选结构，不能固定为所有项目模板。系列差异和复访按 [narrative-and-concept-delivery.md](narrative-and-concept-delivery.md) 核对，普通商业项目不因此强制变文化节或连续剧情。

单元卡至少包含：unit_id/版本、实际内容介绍、服务的人群及目标、为什么参与、观众所见/所做、完成状态、与前后单元的关系、资源与增量成本依据、最大未验证条件及备选；商户/其他承接、线上分支及素材按实际任务记录。场次表落实 session_id、关联单元、日期起止、实际地点/线上场域、适用人数口径、实际嘉宾/创作者角色、负责人、状态、依赖及失败替代。名称和时长不能替代内容。

艺人、嘉宾、KOL/KOC先按任务确定类型与拟邀数量：内容演出/共创/主持、专业解释、本地发现、真实体验、报名召回或二次表达。候选比较记录城市与客群匹配证据、相关作品/近期内容、履约任务、平台/场次、交付数量与形式、费用来源及含税范围、档期/报价状态、素材使用与授权范围、最大风险、替补和最晚确定时间。普通参与者不自动归为KOC；粉丝数不等于本地有效受众、实到或消费。

候选、拟邀、已联系、已询价、已确认等只按实际证据更新；制作了名单不得写“已联系”。未落实的艺人不得成为已定阵容宣传。没有报价可列条件估算或待询价，不能编具体成交价/档期。需要外联时按用户授权另执行。

人数至少区分邀约池、报名、预计实到、同时在场容量、逐场参与人次、全期累计人次、可识别去重人数及不可识别重复。适用项才填；开放街区不虚造报名漏斗。人数由人群目标、容量/吞吐、资源和有来源的历史参数共同约束，依 [registration-and-attendance.md](registration-and-attendance.md) 核算，不从曝光直接换算实到。

## 五、线上分支与逐日内容

有线上任务时，Step 4—5 同时比较核心内容的线上参与价值，选定适合本案且有真实接收端的分支；有线下内容才要求说明与现场的连接，纯线上核对线上观看、投稿、反馈或服务端，纯线下闭门系列不强建线上分支。其他单元可只承担实际需要的服务信息或素材生产。分支可以是征集/共创/任务、观看、探访、攻略、直播或专业解释，不要求所有内容互动或拍摄。禁拍与观看型项目按真实体验和权限处理。

分支卡写清：关联 unit_id/session_id、讲给谁、线上获得什么、用户动作、实际接收端、适用的现场连接、可产生何种素材、下一步承接、负责人及状态。使用征集/任务时补门槛、截止、筛选/判定、结果通知、实际兑现地点或页面/时点/容量、权限、未入选与无法兑现的处理。承诺的兑现端或能力缺失时修复分支；若无可兑现替代，调整承诺、延期或取消并同步通知，不凭“替代”一栏宣称等价，不以总体评分通过。游戏奖池和经济规则引用 [activity-mechanism-search.md](activity-mechanism-search.md)。

有线上线下联动时，线上可以影响现场内容，现场结果也可以引出下一轮线上参与；纯线上则按真实内容、反馈与后续服务连接。画出本项目实际连接及其待验证条件。只对本案采用的官方、媒体、达人、观众表达或付费投放分别说明任务，使用必要渠道，不能统一写成“宣传预热”。

采用的线上与线下宣发触点，沿 [新媒体传播模块](new-media-campaign.md) 二连接同一受众、信息、节点、行动入口与兑现端；现场屏幕、商户、社区等是否可用按真实资源核查。宣传维护信息/稿件与节点版本，执行维护物料、安装、人员及唯一费用，相关到访运营维护实际预约、响应与通知。

逐日内容表覆盖已约定范围，每天至少明确：

`日期/阶段 → 对象与目的 → 关联单元/场次 → 信息主张与内容要点 → 平台/账号 → 形式与asset_id/版本 → 素材来源/状态 → CTA/接收端 → 制作、审核、发布责任与时间 → 预算/指标引用 → 成熟度及替代`

同一天可有多行；不公开发布时记录服务、私域、采集或留白及理由，不能假装漏排日历。未确定日期用相对日期拟排，不能称绝对日历已完成。节目之外也可讲参与者、商户、制作过程、具体问题、成果与下一轮价值，必须有真实内容或明确拟案支撑；避免一个半月只循环倒计时和现场回顾。

连续关键内容在同一日历/稿件记录中说明受众此前所知、本轮新增价值或重复的服务理由，主定义沿 [持续研究生产循环](research-and-content-production-loop.md) 四“新增价值与受众阶段”；实际稿件须能展示差异，不以换标题冒充更新。创作者任务用 [新媒体传播](new-media-campaign.md) 四点六“创作者实际接力”的实际Brief/代表稿与独立入口核对，不能只在名单里命名不同角色。项目/地点记忆与参与理解的原记录按 [数据采集](data-capture-and-review.md) 二维护，受众阶段仅在可识别范围内使用。

**选题日历、素材交接、代表稿和全部成稿是不同深度。** 默认系列全案交逐日信息与内容要点，核心表达给实际标题/主要段落/CTA或代表脚本拟案；用户约定全部成稿时完成全部稿件。未来现场素材标待采集，不能预写已发生的反馈、金句或成果。稿件与素材专业接口继续按 [new-media-campaign.md](new-media-campaign.md)；选题表不能冒充可发布内容，脚本不能冒充视频。

## 六、资源、产能与预算

在 [critical-path-delivery.md](critical-path-delivery.md) 的任务/ROS中接入场次关联及资源占用，不再维护独立且互不相通的排期。资源表按resource_id记录可共享数量/能力及其依据，占用记录session_id或asset_id、数量、使用起止、搭拆/转场/复位缓冲、责任人和确认状态。比较同一资源同一时间的总占用与可用容量；一个摄影师、同一嘉宾、同一场地或唯一设备不能承诺冲突任务。未知容量标待核，不宣称通过。

内容生产同样排产：采集、整理、撰写、剪辑、设计、审核、授权、修改与发布的时点/交接、人员产能及素材依赖。审核或剪辑瓶颈时减少或调整内容，不能仅凭目标发稿数认定产能足够。

费用按cost_id登记一次，标成本类别、覆盖范围/期间、关联资源/场次/资产、数量单价或测算参数、税费口径、包含与未包含项、来源和成熟度。共用舞台/装置、月度达人合作与其他包价只计一次；分摊列用于分析，不再进入总额。场次增量与线上制作/运营/投放分别落在唯一费用项，使用不同名称不能重复登记同一包价。

总预算与现金/应急逻辑按 [business-model-and-budget.md](business-model-and-budget.md)。任何预设应急比例都只是测算假设，按项目风险校准；共享、免费或赞助资源仍须明确已确认/待确认。资源或档期变化后复核费用覆盖、增量/取消费和相关承诺，不能沿用过期总额。

## 七、测量与每周调整

在 Step 2—3 先定目标与 [metrics-flow.md](metrics-flow.md) 的口径。每项指标写对象、窗口、基线、分子/分母（适用时）、来源、采集人、工具/成本、去重能力及限制；主判据由项目实际目标决定。

传播产出/有效兴趣、报名/观看/参与、实到/到访、核销/租户收益与复访分别记录，平台曝光不相加冒充独立触达，逐场人次不相加冒充全期独立人数。官方自报、平台报告、采集实绩与估算保留来源。优惠码/入口归因说明关联，不自动证明增量；商场自然客流、季节/假期、商户促销与其他活动可能影响结果。无可比基线/对照时报告实绩和相关信号，不报活动导致的增长。

效果预测记录“目标值”与“有条件预估”的区别。依据可比历史、本案资源、试验和渠道实测，写假设、参数来源/时效、测算关系、适用容量上限与敏感项；按 `metrics-flow.md` 六以决策需要和数据依据确定是否建立及采用哪些情景，保守/基准/积极仅是可选方式，不锁定档数。没有支撑时只交条件情景、缺口和采数计划，不强填数字。不把用户接受的测算假设升级为已核市场事实，不把现场容量当预计人数。

获得真实数据后，比较本周计划/实绩/覆盖缺口，定位受众匹配、表达、接收端、到访条件、现场体验与商户承接，提出下周内容、邀约、场次或预算的可执行调整。按 [持续循环](research-and-content-production-loop.md) 五把结论回接具体补证任务、实际稿件/素材/服务修改、版本与再核验，不能仅交拟调整表。记录数据依据、影响、负责人、所需决定及观察窗口；未获实绩不写“本周已经优化”。需用户决定的实质取舍按循环一处理，外部执行依授权。复盘和数据留证按 [data-capture-and-review.md](data-capture-and-review.md)。

发布前、场次后、异常时、周度与收尾的适用判断接入 [运营决定](metrics-flow.md) 八，记录继续/调整/暂停/恢复的对象、依据、观察窗口、权限和恢复条件；费用仅引用执行主账。高需求或服务变化按 [接待联动](critical-path-delivery.md) 八点六同步宣传、报名、现场与商户，不能凭热度自行加场。收尾可复用结论沿 [条件性复盘](data-capture-and-review.md) 六注明范围、反证与重查条件，不把单次结果写成永久有效/无效。

## 八、执行工作簿接口

以下六组是**关联信息接口，不是统一Excel的目录**。按 [分工与体验模块](campaign-deliverables-and-playability.md) 一、四分配给创意、执行、宣传及适用扩展工作件；只有相同接手用途的表才在同一可编辑工作簿分表。执行默认Excel管理场次、资源、费用等，创意有实际内容正文，宣传独立维护节点与日历；研究和测量在指定主维护位置。各文件共享项目名称/版本/时区/周期与关键口径，证据、图像、脚本和制作文件通过有效索引连接，不把内部依据全量附给客户，也不固定六个文件。

| 信息组及主维护归属 | 最低内容与连接 |
|---|---|
| 研究与案例索引：指定研究依据文件 | 项目结论/缺口、案例机制与迁移判断、source_id/已核链接/时间/状态及影响对象；只呈现约定客户依据 |
| 活动内容：创意；实际场次：执行 | 创意维护单元正文/版本/系列作用及体验；执行引用unit_id，维护session_id、实际日期起止/点位/人数/状态/依赖/责任/备选；区分复演与新增内容 |
| 邀请：执行履约；角色/任务分别由创意/宣传定义 | 执行主表记录候选证据、关联场次/资产、拟邀数量、费用/档期/履约/授权/替补；内容角色与发布任务用编号引用，不再复制同一名单状态 |
| 逐日内容：宣传日历 | 五节所列日历字段，日覆盖完整，关键代表稿有真实索引，待素材与不发布理由可定位；执行只接制作/采集/审核占用 |
| 资源与预算：执行主账 | resource_id池与占用、制作产能、cost_id唯一费用/覆盖/来源、总额与分析分摊分开、冲突与待核项；线上费用也只记在该主账 |
| 测量与每周调整：指定测量主表/工作件 | metric_id/口径/基线/采集/情景与实绩分开、周计划/实际/问题/决定/影响及状态；继续/调整/暂停/恢复引用metrics-flow八，受影响成本仅引cost_id；未运行的周表保持待采数，其他文件引用而不另记实绩 |

工作底稿可在现有过程文件维护，实际产物按本次用途核验后交付所需文件和约定工作簿，不以旧Step8编号推迟。生成能力不足时交明确命名的可编辑底稿和未交状态，不把Markdown、CSV改后缀或表截图冒充Excel。文件存在、可打开、列完整仍不证明关系正确，需按九节及分工模块五走读。

## 九、联动验收

关键判断、跨文件联动和实际成品按当前用途检查，旧Step7—9的能力可以同轮完成；反馈修改时重核受影响项：

- 任取一个场次：能读懂实际内容和独立价值，找到单元版本、适用邀请角色/人数口径、实际场域与时序、资源、费用和失败处置；有线上任务再核对应分支，不为验收强加宣传。
- 任取一天：能回答对谁讲什么、为何当天讲、依据/素材从哪里来、谁做谁审、看完在哪里做什么；未发生素材不冒充成果。
- 任取一次改期/取消：受影响日历、预告、邀请、资源、预算、通知与测量窗口都有变更/待复核状态；取消历史保留，确认台账不被静默覆盖。
- 复演与共享核对：同单元多场次分别核容量，共用搭建及月度合同一次计费，分摊不再加总。
- 有线上承诺时核兑现：接收端、适用判定/容量与实际内容或服务真实可承接；有线下兑现才查现场。未兑现路径有可实施替代或明确的变更/延期/取消处理，并同步规则、通知与工作表。
- 数据核对：目标/预测/实绩、曝光/人数/人次、归因/增量分开；缺证据就保留限制，不能靠评分通过。
- 各工作件一致：创意、执行、宣传及适用扩展件的日期、内容、嘉宾状态、价格/预算、权益、口径和版本一致；各自有实质正文和明确主维护位置；实际附件可访问，关键表达有代表稿，承诺全部稿件时已逐项完成。不能把不同用途重塞同一Excel或复制独立主账。
- 连续内容与创作者：能指认前后实际稿件的新增价值或必要重复，各创作者贡献与独立入口真实可用；项目与地点理解测试区分内部走读和真实受众记录，不因高曝光判已记住项目。
- 状态与运营决定：点位限制、替代承诺及报名/宣传/现场实际版本一致，能辨明暂停哪项动作、谁决定与何时可恢复；暂停发布不自动取消合同，局部满额不自动关闭全项目。
- 条件性沉淀：归档记录能说明适用人群、时间资源、证据局限、其他解释与重查条件，并检查局部热点对全期制作、服务和预算的影响。

判定注明文件版本与用途，未落实但不影响方向评审的条件可作为待确认项；执行条件不足不得称可直接执行。质量/中标评分仅比较短板，不能替代以上内容证据与用途检查。测试结果、失败与修复写output/run-reviews或本次improvement-log，不直接把项目记录写入方法论。
